Rules of the concept (19)

Book (SW-1e, p. 19 (pdf 29)): “A char is an alphanumeric character or symbol, like the ones that you type.”
Book (OT-Datatypes, ): “The char data type is a single 16-bit Unicode character.”
Rule typeRule
E folk-meaning ruleIn everyday life '7' and 7 are the same thing, and a character is a letter, not a number. A Java char is a 16-bit numeric code: '7' has code 55, and 'a' + 1 is the int 98.
M wrong rule / right ruleCharNotNumeric: wrong: char is not a numeric type | right: A char is encoded as a 16-bit integer, so arithmetic such as 'b' + 'c' or 'a' + 4 works on the character codes.
T uneven-application rulePoints to LT (a char in arithmetic becomes its int code). Applied unevenly, a student treats 'b' + 'c' as 197 in one exercise but prints it as "bc" in another.
N identity rulechar: the primitive type for a single 16-bit Unicode character, such as 'a', '%' or '\n'.
S declarative ruleA char literal is exactly one character (or one escape sequence) in single quotes. Values range from '\u0000' to '\uffff' (0 to 65535), and char is an integral type. A char literal is one character in single quotes ('a'); a String literal is any sequence in double quotes ("a"), so 'a' and "a" have different types and 'ab' does not compile.
LT operational sequencing ruleWhen a char meets an arithmetic operator, it is first promoted to int (its code) and the operation runs in int. Storing the result back in a char needs an explicit cast.
OP evaluation / result ruleSystem.out.println('b') prints b. 'b' + 'c' is the int 197. (char) ('a' + 4) is 'e'.
OS state-transition rulec++ on char c = 'A' makes c 'B', because increment works on chars directly. c = c + 1; does not compile, because the right side is an int.
R composition rule (with a neighbour)with int: A char is stored as an unsigned 16-bit code, so in arithmetic it acts as an int ('a' + 1 is 98). Going from int to char needs a cast.
R composition rule (with a neighbour)with double: A char widens automatically to double (its code), but a double needs a cast to become a char. A char never holds a fractional part.
R composition rule (with a neighbour)with boolean: char and boolean are unrelated: there is no conversion or cast between them, and 'c' is never true or false.
R composition rule (with a neighbour)with char_arithmetic: Char arithmetic works on each char's numeric code and yields an int. A cast turns the result back into a character.
R composition rule (with a neighbour)with primitive_type: char is one of the eight primitive types: the unsigned 16-bit integral one, used for single characters.
P plan / role ruleA char holds one character: processing text one character at a time (charAt), looping over 'A'..'Z', or shifting letters in a cipher.
C conservation ruleChanging 'A' to "A" changes the type to String, so + concatenates instead of adding. Changing a char variable to int keeps the arithmetic, but println then prints numbers instead of letters.
D error rulerule broken: A char literal holds exactly one character. (compile-time)
D error rulerule broken: int arithmetic on chars yields an int, which cannot go into a char without a cast. (compile-time)
D error rulerule broken: A char compares by its code, not by the digit or letter it shows. (silent logic error)
X applicability ruleUse char for one character from a literal or from charAt, especially when the character's code matters (alphabet loops, ciphers). Use String for text of any length.

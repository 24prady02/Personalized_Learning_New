Rules of the concept (21)

Book (SW-1e, p. 7 (pdf 17)): “the second statement calls on System.out.println() to terminate the line.”
Book (OT-Hello, ): “uses the System class from the core library to print the "Hello World!" message to standard output.”
Book (API-PrintStream, ): “println(String x): Prints a String and then terminate the line. This method behaves as though it invokes print(String) and then println().”
Rule typeRule
E folk-meaning ruleEveryday reading: 'println' is just 'print', and 'new line' is something you do before writing. Java rule: println(x) prints x and then ends the line; println() alone just ends the line.
M wrong rule / right ruleIdentifierCaseInsensitive: wrong: System.out.Println and System.out.println name the same method. | right: Java is case-sensitive: names that differ only in capitalization are different names.
M wrong rule / right ruleParenthesesOnlyIfArgument: wrong: () are optional on a no-argument call like println. | right: A method call always needs parentheses, so an empty line is printed with System.out.println();.
M wrong rule / right rulePrintEqualsPrintln: wrong: print and println behave the same. | right: println ends the line after printing and print does not, so print(s1); print(s2); puts s1 and s2 on the same line.
M wrong rule / right rulePrintNewLineFirst: wrong: println(s) prints a newline and then s. | right: println(s) prints s and then the line terminator.
T uneven-application ruleApplies the println rule (print, then end line) unevenly: puts the newline before the text on one call and after it on another, or forgets that the next output starts on a new line.
N identity ruleSystem.out.println is a library method that prints its argument followed by a line terminator ('print line').
S declarative ruleprintln(String x) behaves as though it calls print(x) and then println(); println() terminates the current line by writing the line separator string.
LT operational sequencing ruleEvaluate the argument, print its characters at the current position, then write the line separator so the cursor moves to the beginning of the next line.
OP evaluation / result ruleOutput is the value's characters followed by a line break: println("Hello, "); println("World!"); prints two lines.
OS state-transition ruleOne call appends the text and a line separator to the output; the cursor ends at the start of the next line; no variable changes and nothing is returned.
R composition rule (with a neighbour)with statement: System.out.println(s); is a statement, so its line of output appears at its own place in the sequence.
R composition rule (with a neighbour)with string_literal: println("s") outputs exactly the characters between the quotes and then ends the line.
R composition rule (with a neighbour)with print: print leaves the cursor on the line; println ends it; several prints followed by one println make one line.
R composition rule (with a neighbour)with formatted_output: println prints numbers with all their digits and always ends the line; printf formats each value by its conversion code and ends the line only where the format has %n or \n.
P plan / role rulePurpose: produce one complete line of output, e.g. each result on its own line, or end a line built with print.
C conservation ruleReplacing println with print joins the next output onto the same line (a typical logic error); the characters printed stay the same.
D error rulerule broken: Finish a line of print calls with println (silent logic error)
D error rulerule broken: Method names are case-sensitive (compile-time)
D error rulerule broken: Calls need parentheses (compile-time)
X applicability ruleUse println when each output item belongs on its own line or to end a line; use print to continue a line and printf to control number formatting.

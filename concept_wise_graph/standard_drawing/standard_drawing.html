Rules of the concept (20)

Book (SW-1e, p. 137 (pdf 147)): “The default scale is the unit square (all coordinates between 0 and 1).”
Book (SW-1.5, ): “The default coordinate scale is the unit square (all x- and y-coordinates between 0 and 1).”
Book (StdDraw-API, ): “All subsequent calls to drawing methods such as line(), circle(), and square() will be deffered until the next call to show().”
Rule typeRule
E folk-meaning ruleIn geometry a point has no size, and on screens positions are pixels with y pointing down. StdDraw.point(x, y) draws a visible spot (a circle of the pen radius) in user coordinates: the default is the unit square, with (0, 0) at the lower-left corner.
M wrong rule / right ruleDrawWithoutShow: wrong: With double buffering on, each drawing command appears on screen immediately. | right: By default each command is shown at once. After StdDraw.show(t) turns animation mode on, drawing is collected off-screen and appears only at the next show(t). show() with no argument turns per-command display back on. (Newer StdDraw versions use enableDoubleBuffering().)
M wrong rule / right rulePixelCoordinates: wrong: StdDraw.point(256, 256) draws in the middle of the default window. | right: The default window is 512-by-512 pixels, but coordinates are in the unit square, so the middle is (0.5, 0.5). (256, 256) is far off the canvas.
T uneven-application rulePoints to LT (commands run in program order; each uses the current scale, color and pen radius; later marks cover earlier ones). An uneven trace uses pixel units for some points, puts y downwards, or applies a setting to commands issued before it.
N identity ruleStdDraw is a booksite library of static methods for graphical output: lines, points, shapes and text drawn on a 2-D canvas in a window.
S declarative ruleStdDraw models an abstract device that draws lines and points on a two-dimensional canvas. The default scale is the unit square, and methods with no arguments reset to the defaults.
LT operational sequencing ruleCalls run in program order. Each control command (setXscale, setPenRadius, setPenColor) affects only the drawing commands after it, and each drawing command paints over what is already on the canvas.
OP evaluation / result ruleThe result is a picture in a window, not a value: the methods are void. Triangle's three line() calls and one point() call produce an equilateral triangle with a dot inside.
OS state-transition ruleOne drawing command adds marks to the canvas (shown at once by default). One control command changes the drawing state (scale, pen radius or color) without drawing anything.
R composition rule (with a neighbour)with standard_input: StdIn values can be drawn directly: PlotFilter reads the bounding box, then point coordinates, and calls StdDraw.point for each pair. Both libraries must be downloaded into the program's directory.
R composition rule (with a neighbour)with standard_output: StdOut writes text to a stream, while StdDraw draws in a separate window at (x, y) coordinates. Neither affects the other.
R composition rule (with a neighbour)with animation: Animation reuses StdDraw's drawing commands but adds clear() and show(t), which control when the canvas is erased and displayed.
R composition rule (with a neighbour)with coordinate_scaling: setXscale and setYscale set the coordinate system that every later StdDraw command uses.
R composition rule (with a neighbour)with drawing_shapes: Shape commands are StdDraw drawing commands. They use the same coordinates, pen color and pen radius as line and point.
P plan / role ruleStdDraw is used to visualize data and functions, which is often more meaningful than lists of numbers.
C conservation ruleRescaling the coordinates together with the data keeps the picture. The pen radius is not affected by scaling. Reordering drawing commands changes which mark covers which.
D error rulerule broken: StdDraw.java must be in the working directory or on the classpath. (run-time exception)
D error rulerule broken: Coordinates must lie inside the current scale to be visible. (silent logic error)
D error rulerule broken: setCanvasSize must be called before any drawing. (silent logic error)
X applicability ruleUse StdDraw for simple plots, data visualizations and teaching animations. It is crude compared with production graphics libraries, and exact numeric results belong on standard output.

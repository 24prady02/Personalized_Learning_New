Rules of the concept (25)

Book (SW-1e, p. 103 (pdf 113)): “Java represents a two-dimensional array as an array of arrays.”
Book (OT-Arrays, ): “In the Java programming language, a multidimensional array is an array whose components are themselves arrays.”
Book (SW-1.4, ): “Java represents a two-dimensional array as an array of arrays ... we can use the code a[i] to refer to the ith row (which is a one-dimensional array).”
Rule typeRule
E folk-meaning ruleFolk meaning: a table or matrix is one grid in which rows and columns are symmetric, so a column should be as easy to pick out as a row. Java rule: a 2-D array is an array of row arrays; a[i] is row i, a[i][j] an element, and there is no expression for a column.
M wrong rule / right ruleArrayElementTypeRepeats: wrong: A 2-D int array type is written int[] int[]. | right: It is written int[][]: one element type followed by one bracket pair per dimension.
M wrong rule / right ruleArrayRankIsLength: wrong: The number of dimensions of an array is its length. | right: Rank (number of bracket pairs) and length (number of elements, a.length) are different; a double[][] of size 10-by-3 has a.length == 10.
M wrong rule / right ruleOnlyInnermostArrayElements: wrong: Only the innermost elements are accessible. | right: a[i] gives the whole row i, which can be used like any 1-D array.
M wrong rule / right ruleColumnLikeRow: wrong: Column j of a 2-D array can be picked out as a 1-D array, just like row a[i]. | right: a[i] is row i (a 1-D array), but there is no expression for a column; loop over i and use a[i][j].
M wrong rule / right ruleRaggedRowsSameLength: wrong: All rows of a 2-D array have the same length, so one N works for every row. | right: Rows may differ in length; use a[i].length for row i.
M wrong rule / right ruleMultidimensionalArray: wrong: A 2-D array is one thing, not an array of arrays. | right: A 2-D array is an array of m row arrays, so a[i] is a 1-D array of length n.
M wrong rule / right ruleNoJaggedArrays: wrong: Multi-dimensional arrays must be rectangular. | right: Each row a[i] is its own array, so rows can have different lengths a[i].length.
T uneven-application rulePoints to LT: a[i][j] is evaluated as (a[i])[j], first the row and then the element in it. Inconsistent application: the first index is taken as the row on some steps and as the column on others.
N identity ruleIdentity: a two-dimensional array, an array of arrays used to represent a table or matrix with M rows and N columns.
S declarative ruleDeclarative: declare double[][] a; create with new double[M][N] (rows first, then columns); refer to row i, column j as a[i][j]. Entries start at 0 (numbers) or false (boolean).
LT operational sequencing ruleSequencing: new double[M][N] creates an array of M references and then M row arrays of N defaults. a[i][j] evaluates a[i] (checked against a.length = M) and then [j] (checked against a[i].length).
OP evaluation / result ruleResult: a[i][j] has the element type; a.length is the number of rows M; a[i].length is the length of row i; a[i] is a double[] row.
OS state-transition ruleState transition: a[i][j] = v changes one element of row i; a[i] = new double[K] replaces the whole row i with a new array; other rows are untouched.
R composition rule (with a neighbour)with transition_matrix: The transition matrix is a 2-D double array p[i][j] with one row per page; each row holds a probability distribution.
R composition rule (with a neighbour)with indexing: A 2-D array uses two indices, and the first chooses the row array: a[i][j] is (a[i])[j].
R composition rule (with a neighbour)with ragged_array: Since each row is a separate array, rows may have different lengths; such arrays are ragged.
R composition rule (with a neighbour)with matrix_operations: Matrix operations index a[i][j] in nested loops (two for addition, three for multiplication).
R composition rule (with a neighbour)with multidimensional_array: The same notation extends to any number of dimensions: a[i][j][k] for double[][][].
R composition rule (with a neighbour)with row_major_order: Row-major order visits a[i][j] with the outer loop over rows i; column-major puts the loop over j outside.
P plan / role rulePlan/role: store tables, matrices, grids and images indexed by row and column (grades by student and test, lattice intersections, pixels).
C conservation ruleConservation: swapping the loop order for an element-wise operation keeps the result but changes the processing order. Swapping the indices (a[j][i]) transposes and goes out of bounds when M != N.
D error rulerule broken: Indices must be within each dimension (i < a.length, j < a[i].length). (run-time exception)
D error rulerule broken: The type is written with one bracket pair per dimension. (compile-time)
X applicability ruleApplicability: use a 2-D array for data naturally indexed by two integers (rows by columns). Use a ragged array when rows differ, a 1-D array when one index suffices, and higher dimensions for 3-D models.

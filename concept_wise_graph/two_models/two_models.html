Rules of the concept (16)

Book (SW-1e, p. 168 (pdf 178)): “matter where the surfer starts, the process eventually stabilizes to a point where further surfing provides no further information.”
Book (SW-1e, p. 168 (pdf 178)): “This phenomenon is known as mixing.”

Rule typeRule
E folk-meaning ruleEveryday "model" suggests each program has its own answer; the page ranks are a property of the web model, and simulation and the power method are two ways of computing the same numbers.
M wrong rule / right ruleFewTrialsAreExact: wrong: A short simulation gives the exact page ranks. | right: Simulation estimates; tens of thousands of moves give two accurate places and millions give three, whereas the power method needs about 20 and 40 multiplications.
M wrong rule / right ruleStartPageMatters: wrong: The page ranks depend on which page the surfer starts from. | right: Both models converge to the same probabilities from any start page.
M wrong rule / right ruleManyDigitsMeanAccurate: wrong: A result printed with many decimal places must be accurate to those places. | right: Both programs print five decimals; only the power method after enough iterations is accurate to them.
T uneven-application ruleApplies the two LTs unevenly: e.g. treats one RandomSurfer move as if it advanced the whole probability vector, or one Markov iteration as if it were one sampled move.
N identity ruleTwo computational approaches to page ranks: simulating a random surfer and counting visits, versus mixing the Markov chain by repeated vector-matrix multiplication.
S declarative ruleMixing guarantees a start-independent limit; the power method computes it exactly (up to floating-point precision), whereas the simulation produces an estimate that needs more iterations for more accuracy.
LT operational sequencing ruleSimulation: for T moves, draw r, pick next page, count; then divide counts by T. Power method: for T iterations, multiply the vector by p[][] and replace it; then print the vector.
OP evaluation / result ruleBoth yield about .273 .266 .146 .247 .068 for tiny.txt (RandomSurfer 1000000 vs Markov 40); page 0 beats page 1 by 27.3% to 26.6%.
OS state-transition ruleOne simulation step changes one page variable and one count; one power-method step changes every entry of the probability vector.
R composition rule (with a neighbour)with frequency_counting: freq[j]/T is the simulation's estimate of the same ranks; it carries sampling error the power method does not.
R composition rule (with a neighbour)with power_method: The exact side of the comparison; it reaches two decimals in 20 iterations versus tens of thousands of moves.
P plan / role ruleCross-check and choose a method: agreement of an independent estimate (simulation) with the exact computation validates both and shows the cost of each.
C conservation ruleChanging T or the start page keeps the common limit; rerunning the simulation changes its digits while Markov is deterministic.
D error rulerule broken: Agreement must be judged at the accuracy each method reaches. (silent logic error)
X applicability ruleSimulate when the process is easy to run but its probabilities are hard to write down; use the power method when the matrix is known and fits in memory, since it is far more efficient.

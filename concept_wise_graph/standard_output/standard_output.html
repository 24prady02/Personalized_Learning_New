Rules of the concept (21)

Book (SW-1e, p. 121 (pdf 131)): “Java puts the results of a program's sequence of calls on these methods into the form of an abstract stream of characters known as standard output.”
Book (SW-1.5, ): “Java sends the results to an abstract stream of characters known as standard output.”
Rule typeRule
E folk-meaning ruleNovices take output text literally, as if it acted on the program: printing "The value of X is 1" is read as setting X to 1. They also take 'print' to mean producing a finished line. In Java, print only appends characters to the output stream; it changes no variables and ends the line only for println.
M wrong rule / right rulePrintEqualsPrintln: wrong: print and println behave the same (no newline difference). | right: println(s) prints s and then ends the line, but print(s) does not, so print("a"); print("b"); gives ab on one line.
M wrong rule / right rulePrintfAddsNewline: wrong: printf() ends the line like println(). | right: printf() adds no newline. Put \n (or %n) in the format string to end the line.
M wrong rule / right ruleRepeatedOutputVariablePrintedOnce: wrong: An output statement that names the same variable twice (WRITE y, x, y) prints it only once. | right: Every expression in the output is printed, so System.out.println(y + " " + x + " " + y) with x=6, y=9 prints 9 6 9.
T uneven-application rulePoints to LT (output appears in the order the output calls execute, with a line break only after println). An uneven trace drops a repeated value, puts output lines out of order, or adds line breaks after print on some calls.
N identity ruleStandard output (System.out, StdOut) is the library abstraction for a program's text output: an output stream of characters written by print, println and printf.
S declarative ruleprint(s) writes s. println(s) writes s and then the line separator. println() only ends the line. A null String prints as "null". By default the stream goes to the terminal window.
LT operational sequencing ruleFirst the argument expression is evaluated, e.g. the concatenation "Sum is " + sum. Then its string form is appended, and println appends the line separator after it. Successive calls appear in execution order.
OP evaluation / result ruleThe output is the argument's string form. System.out.println(Math.PI) prints 3.141592653589793 (all digits), and println("Sum is " + 1778) prints Sum is 1778 followed by a newline. The methods return void.
OS state-transition ruleOne call appends text to the output (println also appends the line separator). It changes no variables and returns nothing.
R composition rule (with a neighbour)with stream_model: Each output call appends to the end of the single output stream, so the order of output is the order of execution.
R composition rule (with a neighbour)with redirection: With `> file`, every print/println/printf writes to the file and nothing appears in the terminal. The program code is unchanged.
R composition rule (with a neighbour)with standard_input: A prompt printed with print (not println) shows on the same line where the user then types, before the following StdIn read blocks. Output and input are separate streams.
R composition rule (with a neighbour)with standard_drawing: StdOut text and StdDraw pictures are independent outputs: printing does not draw, and drawing does not print.
R composition rule (with a neighbour)with formatted_output: printf writes to the same stream as print and println, so mixed calls appear in call order. Unlike println, printf ends a line only when the format contains \n.
P plan / role ruleStandard output reports results (to a person, or to a file or program further down the line). Plan: an 'output' step after a computation, or one println per item inside a loop to list values.
C conservation ruleSwitching System.out.print/println to StdOut.print/println keeps the output. Changing println to print keeps every character but removes the line break, so lines join.
D error rulerule broken: Output order and line breaks follow the order of the calls and the print/println choice. (silent logic error)
D error rulerule broken: PrintStream methods never throw IOException; a write failure only sets an internal flag. (silent logic error)
D error rulerule broken: println/print take a single argument; pieces must be joined with +. (compile-time)
X applicability ruleUse standard output for text results meant for a reader or for the next program in a pipeline. Use printf when digits or column widths matter, and StdDraw/StdAudio for pictures and sound.

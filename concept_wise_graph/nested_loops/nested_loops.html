Rules of the concept (23)

Book (SW-1e, p. 58 (pdf 68)): “We refer to the i loop as the outer loop and the j loop as the inner loop.”
Book (SW-1e, p. 58 (pdf 68)): “The inner loop iterates all the way through for each iteration of the outer loop.”
Book (SW-1.3, ): “We can use one or more of them in the body of another statement to make compound statements.”
Rule typeRule
E folk-meaning ruleFolk meaning: 'for each row and each column' sounds like doing two things side by side or one after the other. In Java the inner loop is a statement in the outer body, so it runs all its passes during each single outer pass (like the hands of a clock).
M wrong rule / right ruleInnerOuterSwapped: wrong: The inner loop's variable changes more slowly than the outer loop's. | right: The inner loop runs all its passes for each single pass of the outer loop.
M wrong rule / right ruleNestedLoopsSequential: wrong: The outer loop runs completely, then the inner loop runs completely. | right: The inner loop runs all its passes during each single pass of the outer loop.
M wrong rule / right ruleNestedLoopsLockstep: wrong: Nested loops run in step as one loop: both variables change together and both conditions are tested together. | right: For each pass of the outer loop the inner loop runs all its passes; the inner variable changes fastest.
M wrong rule / right ruleOuterLoopIgnored: wrong: In nested loops only the inner loop repeats; the outer loop runs once. | right: The outer loop repeats as its own condition says, and the inner loop runs fully on each outer pass.
M wrong rule / right ruleInnerCounterOverwritesOuter: wrong: The inner loop count replaces the outer loop count, so the nested loops run as one loop. | right: The two counts multiply: the inner body runs (outer passes) x (inner passes) times.
M wrong rule / right ruleEmptyInnerLoopSkipsRest: wrong: If the inner loop runs zero times, the rest of that outer pass is skipped too. | right: An inner loop that runs zero times just ends; the statements after it in the outer body still run.
T uneven-application ruleApplies the nested-loop rule (LT) unevenly: resets the inner variable on some outer passes but not others, or advances the outer variable in the middle of the inner loop.
N identity ruleNested loops are a loop inside the body of another loop: the outer loop and the inner loop.
S declarative ruleBecause loops are statements, one can be the body of another; the inner loop iterates all the way through for each iteration of the outer loop.
LT operational sequencing ruleOuter init; outer test; [inner init; inner test; inner body; inner update; ... until the inner test fails]; rest of the outer body; outer update; outer test; ... The inner init runs again on every outer pass.
OP evaluation / result ruleThe inner body runs (outer passes) x (inner passes) times: two loops of 1..10 call printf 100 times; DivisorPattern 3 prints 3 rows of 3 entries, each row ending with its row number.
OS state-transition ruleOne outer pass resets the inner variable, runs the complete inner loop, executes the rest of the outer body once, and then updates the outer variable once.
R composition rule (with a neighbour)with for_loop: Usually both loops are for loops: the inner for runs its complete set of passes for every single pass of the outer for.
R composition rule (with a neighbour)with matrix_operations: Matrix addition uses two nested loops over i and j; matrix multiplication adds a third, innermost loop over k for each dot product.
R composition rule (with a neighbour)with labeled_break: A plain break ends only the innermost loop; a labeled break is needed when the inner loop must end the outer one too.
R composition rule (with a neighbour)with row_major_order: Which loop is outside decides the visiting order: row index outside gives row-major order, column index outside gives column-major order.
P plan / role rulePlan: process every pair (i, j) - two-dimensional tables, every row x column of a matrix, every pair of elements; the outer variable is a slow stepper, the inner a fast stepper.
C conservation ruleSwapping the outer and inner loops visits the same pairs in a different order (rows vs columns), which preserves a sum but changes printed layout; moving a statement between the inner body and the outer body changes its count from (outer x inner) to outer.
D error rulerule broken: Without braces, the body of an if, while or for is exactly one statement; indentation does not add statements to it. (silent logic error)
D error rulerule broken: The inner loop needs its own loop variable. (compile-time)
D error rulerule broken: The inner loop must update its own variable. (silent logic error)
X applicability ruleUse nested loops when the work ranges over all combinations of two indices (tables, matrices, pairs); expect running time proportional to the product of the pass counts, and prefer a single loop when the second index is a function of the first.

Rule typeRule
E folk-meaning ruleIn maths `|` means 'divides', absolute value or 'or'. In a command line, `A | B` connects A's standard output to B's standard input.
M wrong rule / right ruleRedirectionIsArgument: wrong: A redirected (piped) stream shows up in args[]. | right: With `A | B`, B's standard input is A's output stream. It is not an argument, and B just reads standard input as if someone were typing it.
T uneven-application rulePoints to LT (A's writes are added to the end of the shared stream and B's reads take from its front, interleaved by the OS). An uneven trace runs A to completion into a file first, or sends B's output back into A.
N identity rulePiping is an operating-system mechanism (`|`) that makes one program's standard output the next program's standard input.
S declarative rule`java RandomSeq 1000 | java Average` specifies that RandomSeq's standard output and Average's standard input are the same stream.
LT operational sequencing ruleThe two programs run together. Each println in A adds a string to the end of the stream, and each read in B removes one from the beginning. The OS decides the interleaving, and the result does not depend on it.
OP evaluation / result ruleOnly the last program's standard output appears. `java RandomSeq 100000 | java Average` prints a single line such as Average is 0.5000499417963857.
OS state-transition ruleOne write by A makes one more item available to B. One read by B consumes it. No file is created.
R composition rule (with a neighbour)with redirection: A pipe has the same effect as `> file` then `< file`, but there is no intermediate file, so the data size is not limited by disk space.
R composition rule (with a neighbour)with filter: Filters are the components and the pipe is the connector: `A | F1 | F2` passes the stream through each filter in turn.
P plan / role rulePiping composes small programs into a pipeline and removes the limit on stream size.
C conservation ruleReplacing `A | B` with `A > f; B < f` keeps the result. Changing A's output format (e.g. adding a label) breaks B's typed reads.
D error rulerule broken: The upstream output must match the downstream input format. (run-time exception)
X applicability ruleUse a pipe when one program's output is exactly the next program's input and the intermediate data need not be kept. Use redirection to a file when it must be saved or reused.

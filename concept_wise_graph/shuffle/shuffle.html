Rules of the concept (17)

Book (SW-1e, p. 93 (pdf 103)): “Second, we ensure that the shuffle is random by choosing uniformly from the cards not yet chosen.”
Book (SW-1.4, p. 93 (pdf 103)): “we pick a random card from deck[i] through deck[n-1] (each card equally likely) and exchange it with deck[i].”
Rule typeRule
E folk-meaning ruleFolk meaning: 'shuffle' means mix randomly, so any random swapping seems good enough. Java/algorithm rule: picking the partner r uniformly from i..N-1 makes all N! orders equally likely; picking from 0..N-1 does not.
M wrong rule / right ruleBiasedShuffle: wrong: Swapping each a[i] with a random element from the whole array gives a uniformly random order. | right: r must be chosen between i and n - 1 for every ordering to be equally likely.
T uneven-application rulePoints to LT: for each i from left to right, compute r in i..N-1 and then exchange deck[i] and deck[r]. Inconsistent application: r is drawn from the whole range on some passes, or the exchange is skipped when r == i.
N identity ruleIdentity: the Knuth (Fisher-Yates) shuffle, which produces a random permutation by exchanging each position, left to right, with a uniformly chosen position at or to its right.
S declarative ruleDeclarative: for (int i = 0; i < N; i++) { int r = i + (int) (Math.random() * (N-i)); exchange deck[i] and deck[r]; }.
LT operational sequencing ruleSequencing: N = deck.length is read once; on each pass r is computed first (Math.random(), times N-i, cast to int, plus i), then the three-step exchange runs, then i increases.
OP evaluation / result ruleResult: a permutation of the original elements with every one of the N! orders equally likely; the output differs from run to run.
OS state-transition ruleState transition: one pass picks r and exchanges deck[i] with deck[r]; afterwards deck[0..i] is fixed for the rest of the shuffle.
R composition rule (with a neighbour)with array_exchange: Using the exchange idiom guarantees the deck holds the same cards after the shuffle.
R composition rule (with a neighbour)with math_library: (int) (Math.random() * (N-i)) is a uniform int in 0..N-i-1, so r = i + that value is uniform in i..N-1.
R composition rule (with a neighbour)with sampling_without_replacement: Stopping the shuffle after the first M passes leaves a uniform random sample in positions 0..M-1.
P plan / role rulePlan/role: randomize the order of an array in place in linear time (dealing cards, random permutations); the array is an organizer.
C conservation ruleConservation: the set of cards is invariant (exchanges only), and after pass i, deck[0..i] is a uniform random sample. Widening r's range to 0..N-1 keeps the set but breaks uniformity.
D error rulerule broken: r must be uniform over i..N-1. (silent logic error)
D error rulerule broken: The cast applies to the scaled product. (silent logic error)
D error rulerule broken: r must stay within 0..N-1. (run-time exception)
X applicability ruleApplicability: use it to randomize a whole array in place. For only M random items, run the first M passes. When the original order must be kept, shuffle an index permutation and use it to index the data.

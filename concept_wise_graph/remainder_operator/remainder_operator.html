Rules of the concept (16)

Book (SW-1e, p. 21 (pdf 31)): “the value of a % b is the remainder that you get when you divide a by b.”
Book (SW-1e, p. 38 (pdf 48)): “The quotient a / b rounds toward 0; the remainder a % b is defined such that (a / b) * b + a % b is always equal to a.”
Book (OT-Op1, ): “The only symbol that might look new to you is "%", which divides one operand by another and returns the remainder as its result.”
Book (RS, ): “x % y = x - (x / y) * y”
Book (RS, ): “the expression 10.2 % 2.4 evaluates to 0.6 because you can take away four 2.4's from 10.2, leaving you with 0.6 left over.”
Rule typeRule
E folk-meaning ruleIn everyday use % means percent (50% of x), and in maths 'mod' always gives a non-negative result. In Java % is the remainder of truncating division, and its sign follows the left operand (-14 % 3 is -2).
M wrong rule / right ruleRemainderIsQuotient: wrong: 17 % 5 is 3 (the quotient). | right: % returns the remainder, so 17 % 5 is 2.
M wrong rule / right ruleNegativeRemainderSign: wrong: a % b is never negative, and integer division of a negative number rounds down. | right: a / b rounds toward 0 and a % b takes the sign of a: -14 / 3 is -4 and -14 % 3 is -2.
T uneven-application rulePoints to LT (compute the truncated quotient, then the remainder). Applied unevenly, a student gives the remainder for positive operands but the mathematical mod for negatives, or swaps quotient and remainder (17 % 5 as 3).
N identity ruleRemainder operator %: the binary operator that gives the remainder after dividing a by b.
S declarative ruleFor ints, a % b is defined so that (a / b) * b + a % b equals a. The result takes the sign of a, % by zero throws ArithmeticException, and % also works on doubles.
LT operational sequencing ruleEvaluate a, then b, take the quotient rounded toward 0, and give what is left over. % has the same precedence as * and /, and they group left to right.
OP evaluation / result rule17 % 3 is 2, 76 % 12 is 4, 1234 % 99 is 46, -14 % 3 is -2, and 14 % -3 is 2.
OS state-transition ruler = a % b stores a remainder smaller in size than b and leaves a and b unchanged. If b is 0, ArithmeticException is thrown before anything is stored.
R composition rule (with a neighbour)with integer_division: % is the companion of integer division, since a == (a / b) * b + a % b. Both use the same quotient rounded toward 0.
P plan / role rulePlans: divisibility and parity tests (x % 2 == 0), digit extraction (x % 10), cyclic wrap-around ((i + 1) % n), leap-year rules, and splitting units (76 % 12 inches).
C conservation ruleNegating a flips the remainder's sign, so n % 2 == 1 fails for negative odd n while n % 2 != 0 still works. Changing the divisor changes the cycle length. Swapping % with / swaps the remainder for the quotient.
D error rulerule broken: int remainder by zero is undefined. (run-time exception)
D error rulerule broken: The remainder takes the sign of the dividend. (silent logic error)
D error rulerule broken: % is the remainder, not a percentage. (silent logic error)
X applicability ruleUse % for divisibility, parity, digits, cyclic indices and unit splitting. Do not use it for percentages (use * / 100.0), and do not use it where a non-negative mathematical mod is needed for negative values (adjust the result or use Math.floorMod).

Rules of the concept (14)

Book (SW-1e, p. 31 (pdf 41)): “the library method Math.round() takes a double argument and returns a long result: the nearest integer to the argument.”
Book (SW-1.2, ): “Call methods such as Math.round(), Integer.parseInt(), and Double.parseDouble().”
Rule typeRule
E folk-meaning ruleFolk meaning: 'round x' (as in school or on a calculator) changes x itself into a whole number, of the ordinary integer kind. Java rule: Math.round(x) leaves x unchanged and returns a new value, the nearest integer, of type long (ties go up, so Math.round(2.5) is 3 and Math.round(-2.5) is -2).
M wrong rule / right ruleCastRounds: wrong: (int) 2.7 evaluates to 3. | right: A cast to int discards the fractional part (rounds toward zero, so (int) -2.7 is -2); Math.round rounds to the nearest integer.
T uneven-application rulePoints to LT (evaluate the argument, round it, return a long that must be stored or used). Applied unevenly: the student stores the rounded value in one step but on another line assumes the call itself changed x, or treats the result as an int in one place and as a long elsewhere.
N identity ruleMath.round is a Math library (explicit conversion) method that takes a double and returns the nearest integer as a long.
S declarative ruleSignature long round(double a): round to the nearest integer; the result is long, so storing it in an int requires an explicit cast, as in (int) Math.round(x).
LT operational sequencing ruleIn int n = (int) Math.round(x * 10): evaluate x * 10, call Math.round on that double, which returns a long, apply the (int) cast, then assign to n.
OP evaluation / result ruleType long: Math.round(3.14159) and Math.round(2.71828) are both 3; Math.round(Math.PI * 20.0) is 63; (int) Math.round(2.71828) is int 3.
OS state-transition ruleThe call changes no variable: x keeps its value; the only state change is the assignment of the returned long, e.g. long r = Math.round(x);.
R composition rule (with a neighbour)with math_library: Math.round is listed in the Math API with return type long, which is what forces the cast when the result goes to an int (unlike the other Math methods, which return double).
P plan / role ruleConverts a computed real value to the nearest whole number for counting, display or pixel coordinates, typically as (int) Math.round(x).
C conservation ruleReplacing Math.round(x) with (int) x changes the result whenever the fractional part is .5 or more (and for negative values), because the cast truncates toward zero; adding the (int) cast keeps the value as long as it fits in the int range.
D error rulerule broken: Math.round(x) returns a value and does not change x; the value must be stored or used. (silent logic error)
D error rulerule broken: Math.round(double) returns a long, so storing it in an int needs a cast: int n = (int) Math.round(x); (compile-time)
X applicability ruleUse Math.round when the nearest integer is wanted; use a cast when truncation toward zero is wanted; to round only what is printed (e.g. two decimals), use printf instead of changing the value.

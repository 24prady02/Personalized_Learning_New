Rule typeRule
E folk-meaning ruleIn maths classes a transition matrix is often written column-wise (column = from), and "matrix" suggests a table of counts; in SW p[i][j] is a probability, row i = the page the surfer is on, column j = the page moved to, and each row sums to 1.
M wrong rule / right ruleMultidimensionalArray: wrong: A 2-D array is one thing, not an array of arrays. | right: Java represents p[][] as an array of N row arrays; p[page] is itself a 1-D double array (the distribution used by the random move).
M wrong rule / right ruleNoJaggedArrays: wrong: Multi-dimensional arrays must be rectangular. | right: Each row is its own array, so rows can differ in length (a ragged array); the transition matrix is created square with new double[N][N].
M wrong rule / right ruleRowsNeedNotSumToOne: wrong: A page with no outgoing links can have an all-zero row. | right: Every row must be a probability distribution summing to 1; a page with no links gets 1/N in every column.
T uneven-application ruleApplies LT (for each row i, for each column j: .90*counts[i][j]/outDegree[i] + .10/N) unevenly: e.g. adds the .10/N leap term only to entries that have a link, or divides by outDegree[j] (the column page) on some entries, so some rows no longer sum to 1.
N identity ruleA data structure: an N-by-N two-dimensional double array p[][] (a stochastic matrix) whose entry p[i][j] is the probability of moving from page i to page j.
S declarative ruleEntry (i, j) is the probability that the surfer on page i moves to page j; by the 90-10 rule it is .90*counts[i][j]/outDegree[i] + .10/N, and every row is a discrete probability distribution summing to 1.
LT operational sequencing ruleThree steps in order: read N and create counts[][] and outDegree[]; read all links and accumulate counts; then, row by row (outer i) and column by column (inner j), compute and print one probability; the header "N N" is printed before the rows.
OP evaluation / result ruleOutput is a matrix file: the row and column counts, then N rows of N doubles printed with %8.5f; for tiny.txt row 0 is 0.02000 0.92000 0.02000 0.02000 0.02000 and row 1 is 0.02000 0.02000 0.38000 0.38000 0.20000.
OS state-transition ruleOne inner-loop pass evaluates one double p for the current (i, j) from counts[i][j], outDegree[i] and N, and prints it; no array is modified by this phase.
R composition rule (with a neighbour)with input_graph: Row i depends only on the tallies read for page i (counts[i][] and outDegree[i]); the matrix cannot be computed until all links have been read.
R composition rule (with a neighbour)with normalization: Dividing counts[i][j] by outDegree[i] (after scaling by .90) and adding .10/N is the normalisation that makes row i sum to 1; the double operand .90 keeps the division from being integer division.
R composition rule (with a neighbour)with random_move: The random move reads one row p[page] as a 1-D array and accumulates its entries; it only works if that row sums to 1.
R composition rule (with a neighbour)with two_dimensional_array: The matrix is double[N][N]: p[i] is the row array for page i and p[i][j] an element; indices must be in 0..N-1 and the first index is the row (from-page).
R composition rule (with a neighbour)with markov_chain: A matrix whose rows are probability distributions defines a Markov chain: the next page depends only on the current page's row.
R composition rule (with a neighbour)with dangling_pages: Transition's formula is valid only if every outDegree[i] > 0; a page with no outlinks must have its row filled with 1/N.
R composition rule (with a neighbour)with teleportation: The .10/N term, added to every entry, is the teleport (random-page) part of each row; the .90 factor scales the link part so the two parts sum to 1.
P plan / role ruleSpecifies completely the surfer's behaviour as data; Transition is a filter turning the list-of-links representation into a matrix that RandomSurfer and Markov both read.
C conservation ruleInvariant: every row sums to 1. Changing the split to 80-20 or 95-5 keeps it (the two weights still sum to 1) but changes the ranks; changing .10/N to .10, or omitting the leap term, breaks it.
D error rulerule broken: outDegree[i] must be > 0 (no dangling pages). (silent logic error)
D error rulerule broken: Each row must sum to 1. (silent logic error)
D error rulerule broken: Indices i, j must be in 0..N-1. (run-time exception)
X applicability ruleRight tool when the model has few enough pages that N*N doubles fit in memory and both simulation and the power method need per-pair probabilities; not for millions of pages (trillions of entries).

Rules of the concept (14)

Book (SW-1e, p. 105 (pdf 115)): “is known as row-major order”
Book (SW-1e, p. 105 (pdf 115)): “known as column-major order”
Rule typeRule
E folk-meaning ruleFolk meaning: tables are read left to right, top to bottom, as the only natural order, and 'row' and 'column' are easily swapped. Rule: the loop that is outside decides the order: an outer loop over rows i gives row-major order, an outer loop over columns j gives column-major order.
T uneven-application rulePoints to LT: the inner loop runs through completely for each value of the outer loop. Inconsistent application: the trace advances the outer index after every inner step, or swaps which index belongs to which loop.
N identity ruleIdentity: row-major order processes a 2-D array row by row; column-major order processes it column by column.
S declarative ruleDeclarative: for (i < M) { for (j < N) ... a[i][j] } is row-major; for (j < N) { for (i < M) ... a[i][j] } is column-major. Both keep a[i][j] with i as the row.
LT operational sequencing ruleSequencing (row-major print): i = 0, j runs over 0..N-1 printing a[0][j], newline; i = 1, ... So a[0][0], a[0][1], ..., a[1][0], ... in that order.
OP evaluation / result ruleResult: row-major processing yields per-row results (row averages in column N, rows printed as lines); column-major yields per-column results (column averages in row M).
OS state-transition ruleState transition: each inner step processes one entry; each outer step completes one whole row (row-major) or column (column-major) and resets the per-row sum.
R composition rule (with a neighbour)with two_dimensional_array: Because a[i] is a row array, row-major order walks along each row array in turn; column-major jumps between row arrays at each step.
R composition rule (with a neighbour)with nested_loops: Which loop is outside decides whether entries are processed row by row or column by column; the inner loop finishes for each outer value.
P plan / role rulePlan/role: choose the order that matches the result wanted, row-major for per-row results (and for printing), column-major for per-column results.
C conservation ruleConservation: swapping the loops of an element-wise operation (copy, add) keeps the result and changes only the visiting order. For printing or per-row sums, swapping changes the output (transposed layout, column results).
D error rulerule broken: Each loop bound must match the index it controls (i < M rows, j < N columns). (run-time exception)
D error rulerule broken: Per-row or per-column accumulators must be reset for each outer pass. (silent logic error)
X applicability ruleApplicability: use row-major by default in Java (rows are arrays; printing goes line by line). Use column-major when the result is per column, and remember that ragged arrays have no full columns.

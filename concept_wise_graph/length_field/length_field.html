Rules of the concept (17)

Book (SW-1e, p. 89 (pdf 99)): “Java's standard mechanism is to allow a program to refer to the length of an array a[] with the code a.length”
Book (OT-Arrays, ): “Finally, you can use the built-in length property to determine the size of any array.”
Book (SW-1.4, ): “You can refer to the length of an a[] in your program with the code a.length.”
Rule typeRule
E folk-meaning ruleFolk meaning: 'length' is something you ask for, like s.length() for a String, and in everyday counting 'length 10' suggests the last item is number 10. Java rule: a.length is a final field written without parentheses, equal to the number of elements, so the last index is a.length-1.
M wrong rule / right ruleArrayHasLengthMethod: wrong: You call length() instead of using the length field. | right: An array's size is the field a.length, written without parentheses; length() is a String method.
M wrong rule / right ruleArrayLengthCannotBeZero: wrong: An array cannot have length 0. | right: new int[0] is a legal array with length 0; args is such an array when no arguments are typed.
T uneven-application rulePoints to LT: a.length is read every time the loop test i < a.length runs. Inconsistent application: the trace uses a.length as the last valid index on some passes (as if the test were <=).
N identity ruleIdentity: a.length is the public final instance field that every array has, holding its number of elements.
S declarative ruleDeclarative: the length of array a is written a.length (no parentheses); it equals the size given at creation, may be zero, cannot be assigned, and the last element is a[a.length-1].
LT operational sequencing ruleSequencing: a is evaluated first (a null a throws NullPointerException), then the length field of the array a refers to now is read. In 'for (int i = 0; i < a.length; i++)' it is re-read at each test.
OP evaluation / result ruleResult: an int >= 0 equal to the number of elements: new double[8].length is 8, {1, 2, 3}.length is 3, and the last element is a[a.length-1].
OS state-transition ruleState transition: reading a.length changes nothing. Assigning 'a.length = 5' is impossible (a final field), so only making a refer to a different array changes the value later read as a.length.
R composition rule (with a neighbour)with array_creation: The n given to new becomes a.length and stays fixed for that array object.
R composition rule (with a neighbour)with args_length: args is an ordinary String[], so args.length is its length field and counts the command-line arguments (0 when none are typed).
P plan / role rulePlan/role: a fixed value (Sajaniemi) that lets code adapt to any array size instead of a hard-coded magic number, e.g. loop bounds and the last element.
C conservation ruleConservation: for a given array object a.length never changes, so loops bounded by a.length stay correct when the array is created with a different size. Reassigning a to another array changes a.length.
D error rulerule broken: length is a field, not a method. (compile-time)
D error rulerule broken: length is final and cannot be assigned. (compile-time)
D error rulerule broken: The last valid index is a.length-1. (run-time exception)
X applicability ruleApplicability: use a.length wherever code must follow the array's real size (loop bounds, last element, copying); use a[i].length for each row of a possibly ragged 2-D array; use s.length() for Strings.

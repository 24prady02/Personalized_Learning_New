Rules of the concept (28)

Book (SW-1e, p. 87 (pdf 97)): “To create it, you need to specify its size (the number of values).”
Book (SW-1e, p. 89 (pdf 99)): “The reason that we need to explicitly create arrays at runtime is that the Java compiler cannot know how much space to reserve for the array at compile time”
Book (OT-Arrays, ): “An array is a container object that holds a fixed number of values of a single type. The length of an array is established when the array is created. After creation, its length is fixed.”
Book (SW-1.4, ): “if we have n values, we think of them as being numbered from 0 to n-1.”
Rule typeRule
E folk-meaning ruleFolk meaning: in maths, a[5] or a_5 names element 5, and 'new' means 'fresh, empty, ready to fill', so 'new int[5]' is read as 'element 5' or as an empty list that grows. Java rule: new int[n] allocates exactly n elements, indexed 0 to n-1, each already set to the default value, and the length can never change.
M wrong rule / right ruleArrayAllocationWithoutNew: wrong: Arrays are created without the new keyword. | right: An array exists only after new T[n] (or an initializer list in a declaration, which implies creation) has run.
M wrong rule / right ruleArrayRangeInclusive: wrong: new int[n] has slots 0 to n, inclusive. | right: new int[n] has exactly n slots, a[0] through a[n-1]; a[n] does not exist.
M wrong rule / right ruleArraysGrow: wrong: An array grows as you add elements. | right: An array's length is fixed when it is created, so writing to a[n] throws an exception instead of adding a slot.
M wrong rule / right ruleDeclarationCreatesArray: wrong: int[] a; already makes an array that can be indexed. | right: Only new (or an initializer) creates the array; before that, using a[i] is the compile-time error 'variable a might not have been initialized'.
M wrong rule / right ruleArrayBracketCountIsLength: wrong: The number of brackets in new int[][] is the array's length. | right: Bracket pairs give the number of dimensions; the length is the value of the dimension expression inside them.
M wrong rule / right ruleArrayLengthCannotBeZero: wrong: An array cannot have length 0. | right: new int[0] is a legal array with a.length == 0 (no element can be indexed).
M wrong rule / right ruleArrayCreationIsFree: wrong: Creating a big array with new takes no time because the elements are not set yet. | right: Java initializes every element when the array is created, so creation takes time proportional to its length.
T uneven-application rulePoints to LT: evaluate the size, allocate the array, fill it with defaults, return the reference, then assign it. Inconsistent application: the size n is treated as the last index on some lines, or the array is assumed to exist already at its declaration.
N identity ruleIdentity: an array creation expression; new T[n] makes a new array object with n elements of type T and yields a reference to it.
S declarative ruleDeclarative: 'new T[expr]', where expr is any int-valued expression evaluated at run time; the resulting length is fixed for the array's lifetime.
LT operational sequencing ruleSequencing: (1) the dimension expression is evaluated; (2) if it is negative, NegativeArraySizeException is thrown; (3) space for n elements is reserved and every element is set to its default; (4) the expression yields the reference, which an enclosing assignment then stores.
OP evaluation / result ruleResult: a value of type T[], namely a reference to a new array of length n whose elements all hold the default (0, 0.0, false or null). It produces no output; printing it shows an address, not the elements.
OS state-transition ruleState transition: one execution creates one new array object (n new element variables at their defaults) and returns its reference. No existing variable changes until that reference is assigned.
R composition rule (with a neighbour)with array_declaration: The declared element type must match the created one; in 'double[] a = new double[N];' the left side is the declaration and the right side is the creation.
R composition rule (with a neighbour)with indexing: Elements can be indexed only after creation, and the n given to new fixes the valid index range 0..n-1.
R composition rule (with a neighbour)with array_default_values: Creation is what puts the default value (0, 0.0, false, null) in every slot; each execution of new gives fresh defaults.
R composition rule (with a neighbour)with length_field: The size n given to new becomes a.length and never changes for that array object.
R composition rule (with a neighbour)with array_initializer: An initializer {v0, ..., vk} implies creation of an array of length k+1, so new is not written.
R composition rule (with a neighbour)with array_aliasing: Only new makes a distinct array. Assignment copies the reference, so a separate copy needs new plus an element-by-element copy.
R composition rule (with a neighbour)with array_reference: new yields the reference (address) of the array, and the array variable stores that reference, not the elements.
P plan / role rulePlan/role: reserve storage for a number of values that may be known only at run time (e.g. N from the command line), before any value is stored.
C conservation ruleConservation: changing n changes a.length and the valid index range but not the element type. Moving 'new' inside a loop gives a fresh array of defaults on every pass (SelfAvoidingWalk relies on this). Re-creating an array never changes arrays that other variables already refer to.
D error rulerule broken: The dimension expression of new must be >= 0. (run-time exception)
D error rulerule broken: An array must be allocated with new before its elements are accessed. (compile-time)
D error rulerule broken: The dimension expression must have an integral type (int after promotion). (compile-time)
D error rulerule broken: The requested array must fit in the memory available to Java. (run-time exception)
X applicability ruleApplicability: use new T[n] when the number of values is known (at least at run time) before they are stored and stays fixed. Use an initializer when the values are compile-time constants, and a resizing structure when the count is unknown in advance.

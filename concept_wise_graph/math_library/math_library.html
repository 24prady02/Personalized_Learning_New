Rules of the concept (21)

Rule typeRule
E folk-meaning ruleFolk meaning: the calculator's function buttons, which work in degrees, round 2.7 to 3 when 'converting to a whole number', and always give a non-negative absolute value. Java rule: Math's trigonometric methods take radians, a cast to int truncates (only Math.round rounds, returning a long), and integer overflow makes Math.abs(-2147483648) negative.
M wrong rule / right ruleCastRounds: wrong: (int) 2.7 evaluates to 3. | right: A cast to int discards the fractional part (rounds toward zero, so (int) -2.7 is -2); Math.round rounds to the nearest integer.
T uneven-application rulePoints to LT (the argument is evaluated, then the method computes from it). Applied unevenly: within one trace the student feeds degrees to Math.sin on one call and radians on another, or rounds the result of one call and truncates another.
N identity ruleThe Math library is Java's class Math (in java.lang, no import needed) of static methods for mathematical functions (abs, max, min, sin, cos, tan, exp, log, pow, sqrt, round, random) and the constants PI and E.
S declarative rulePer the API: double abs/max/min (also for int, long, float), double sin/cos/tan(double theta) with theta in radians, double exp, log (natural), pow(a, b), sqrt; long round(double); double random() in [0, 1); constants Math.PI and Math.E.
LT operational sequencing ruleFor Math.f(arg): evaluate arg (an int argument is widened to double), call the method, use the returned double in the enclosing expression; in nested calls the innermost runs first.
OP evaluation / result ruleMath.sqrt(2.0) is 1.4142135623730951, Math.sqrt(-1.0) is NaN, Math.sin(Math.PI/2) is 1.0, Math.log(Math.E) is 1.0, Math.pow(2.0, 10.0) is 1024.0, and Math.abs(-2147483648) is -2147483648.
OS state-transition ruleAll the listed Math methods except random() are mathematical functions: they change no variable and return the same result for the same argument; random() takes no argument and returns a different value on each call.
R composition rule (with a neighbour)with method_call: Every Math facility is used through a method call with the Math. prefix and parentheses (the constants Math.PI and Math.E are written without parentheses).
R composition rule (with a neighbour)with shuffle: In the shuffle, r = i + (int) (Math.random() * (N-i)) scales Math.random() to a uniformly random position between i and N-1, so each remaining card is equally likely.
R composition rule (with a neighbour)with standard_audio: Each sample a[i] = Math.sin(2*Math.PI * i * hz / sps) is taken at evenly spaced times; the 2*Math.PI factor is needed because Math.sin works in radians, one cycle being 2 pi.
R composition rule (with a neighbour)with math_random: Math.random() is the one Math method that takes no argument and is not a mathematical function: it returns a random double in [0, 1).
R composition rule (with a neighbour)with math_round: Math.round is the Math method that rounds to the nearest integer, but it returns a long, so storing it in an int needs a cast.
R composition rule (with a neighbour)with trig_functions: The trigonometric functions are Math methods whose angles are in radians; Math.toRadians and Math.toDegrees convert.
R composition rule (with a neighbour)with random_move: The random move draws r = Math.random() once per move and compares it with growing cumulative sums of row p[page] to find which interval contains it.
P plan / role ruleUsed as a black box for standard numeric computations so that a program reads like the formula, e.g. Quadratic computes double d = Math.sqrt(discriminant);.
C conservation ruleReplacing Math.pow(x, 2) by x * x keeps the value (up to rounding) and is cheaper; replacing Math.round(x) by (int) x changes results whenever the fractional part is at least .5 (and for negatives); replacing Math.sin(x)/Math.cos(x) by Math.tan(x) keeps the value.
D error rulerule broken: Library methods are called with the class name, e.g. Math.sqrt(x). (compile-time)
D error rulerule broken: Each argument must have the type the method's API lists. (compile-time)
D error rulerule broken: Math.sqrt and Math.log are undefined for negative arguments and return NaN. (silent logic error)
X applicability ruleUse Math for standard functions (roots, logs, trig, extremes, rounding, randomness); for squaring or small known integer powers multiply instead of calling Math.pow, and write known powers of ten as literals such as 1e6.

Rules of the concept (13)

Book (RS-web, ): “We print n letters but need only n - 1 commas.”
Rule typeRule
E folk-meaning ruleFolk meaning: in everyday counting each item 'comes with' its separator (each fence section with a post), so a novice prints item and separator together n times. For n items you need n − 1 separators (or n + 1 posts for n sections), so one item has to be handled outside the loop.
T uneven-application ruleApplies the loop's LT rule unevenly: on a trace, the first item is printed both before the loop and on the first pass (loop starting at 0 instead of 1), or the separator is printed before the test on the last pass. The result is a duplicated first item or a trailing separator.
N identity ruleLoop idiom: a loop that processes n items with n − 1 separators by handling one item outside the loop ('loop and a half').
S declarative rulePrint the first item before the loop, then loop over the rest printing separator then item: `System.out.print(a[0]); for (int i = 1; i < n; i++) System.out.print(", " + a[i]);` (or print item then separator for all but the last).
LT operational sequencing ruleOrder: the first item is printed once before the loop test. Each pass then tests `i < n`, prints the separator, prints a[i] and increments i, so a separator always comes before an item, never after the last one.
OP evaluation / result ruleFor a = {1, 2, 3} the output is `1, 2, 3`: 3 items and exactly 2 separators, with no leading or trailing separator.
OS state-transition ruleOne loop pass prints exactly one separator and one item and increments i by 1. The pre-loop statement prints one item and no separator.
R composition rule (with a neighbour)with for_loop: The for loop's bounds must match the handled-outside item: if a[0] is printed before the loop, the loop must start at `i = 1`. Starting at 0 duplicates the first item, and `i <= n` runs past the end.
P plan / role rulePlan: fencepost / loop-and-a-half plan. It produces separated lists (`1, 2, 3`), joined strings, and drawings of n posts with n − 1 rails.
C conservation ruleInvariant: after k passes, the output holds k + 1 items and k separators. Moving the separator after the item inside the loop breaks this and leaves a trailing separator. Swapping the outside item from first to last needs the loop to cover 0 .. n−2 instead.
D error rulerule broken: n items need n − 1 separators; one item must be handled outside the loop. (silent logic error)
D error rulerule broken: Array indices run from 0 to length − 1; the item handled outside the loop must exist. (run-time exception)
X applicability ruleUse a fencepost loop whenever items are joined by separators or bounded by posts (CSV lines, comma lists, drawings). It is not needed when every item gets the same surrounding text; there, a plain loop is right.

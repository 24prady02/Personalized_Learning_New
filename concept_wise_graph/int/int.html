Rules of the concept (22)

Book (SW-1e, p. 21 (pdf 31)): “An int is an integer (natural number) between -2147483648”
Book (OT-Datatypes, ): “By default, the int data type is a 32-bit signed two's complement integer”
Book (SW-1.2, ): “An int is an integer (whole number) between -2^31 and 2^31 - 1.”
Rule typeRule
E folk-meaning ruleIn maths integers are unbounded, and dividing two integers can give a fraction (10 / 3 = 3.33...). A Java int has a fixed 32-bit range, its / discards the fraction, and results outside the range wrap around.
M wrong rule / right ruleIntOverflowWidensAutomatically: wrong: An int result that is too large is automatically stored as a bigger number. | right: int arithmetic is 32-bit; a result outside the range wraps around.
M wrong rule / right ruleIntegerDivisionGivesFraction: wrong: 10 / 3 evaluates to 3.333.... | right: Dividing two ints gives an int: the fractional part is discarded.
T uneven-application rulePoints to LT (each int operation is done immediately in 32-bit integer arithmetic). Applied unevenly, a student truncates 10 / 3 to 3 in one step but computes 10 / 3 * 3 as 10, or wraps on one overflow but not another.
N identity ruleint: Java's 32-bit signed integer primitive type.
S declarative ruleint values run from -2147483648 to 2147483647. + - * / % take two ints and produce an int. / discards the fraction, and division or remainder by zero is not allowed.
LT operational sequencing ruleAn int expression evaluates its operands left to right and applies * / % before + -. Each operation is done at once in 32-bit precision, so every intermediate result is already truncated or wrapped.
OP evaluation / result ruleThe result is an int: 5 + 3 is 8, 5 / 3 is 1, 5 % 3 is 2, 3 * 5 - 2 is 13, and 1 / 0 is a run-time error.
OS state-transition ruleAn assignment like n = n + 1 changes n by exactly 1, with no rounding. A result outside the range is stored wrapped around.
R composition rule (with a neighbour)with double: int op double promotes the int and gives a double. A double becomes an int only through a cast, which truncates toward zero.
R composition rule (with a neighbour)with boolean: int and boolean do not convert into each other. Comparing ints gives a boolean (x > 0), and an int cannot itself be used as a condition.
R composition rule (with a neighbour)with char: In arithmetic a char is promoted to its int code. An int becomes a char only through a cast.
R composition rule (with a neighbour)with overflow: Because int has a fixed 32-bit range, results outside it wrap around silently.
R composition rule (with a neighbour)with long_type: If either operand is long, the operation is 64-bit and the result is long. Storing a long into an int needs a cast.
R composition rule (with a neighbour)with int_literal_limit: An int literal must lie in int's range, so larger digit strings need an L (long) literal.
R composition rule (with a neighbour)with primitive_type: int is the 32-bit integral primitive type, and the default type for integer literals and arithmetic.
P plan / role ruleint is used for counting and indexing: counters, loop steppers, array indices, sizes, and exact whole quantities (cents).
C conservation ruleChanging a variable from int to double changes / from truncating to fractional, and output from 3 to 3.0. Multiplying before dividing keeps precision (59 * 100 / 60 is 98, but 59 / 60 * 100 is 0).
D error rulerule broken: int division and remainder by zero are undefined. (run-time exception)
D error rulerule broken: int results are only 32 bits and overflow is not reported. (silent logic error)
D error rulerule broken: A double cannot be stored in an int without a cast. (compile-time)
X applicability ruleUse int for whole quantities that stay under about 2 billion (counts, indices, cents). Use long beyond that, BigInteger when values are unbounded, and double for measurements or fractions.

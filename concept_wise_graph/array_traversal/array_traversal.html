Rules of the concept (26)

Book (TJ-2e, p. 113 (pdf 135)): “Looping through the elements of an array is called a traversal”
Book (OT-Arrays, ): “for (int i = 0; i < a.length; i++) visits every valid index once: numbering begins with 0 and the built-in length property gives the size.”
Rule typeRule
E folk-meaning ruleFolk meaning: 'go through the list' in English means look at every item once, first to last, so an array loop is assumed to process the whole array whatever its code says. Java rule: the loop visits exactly the indices its initialization, guard and update generate, in that order.
M wrong rule / right ruleOffByOneBound: wrong: < vs <= and 0..n vs 0..n-1 are interchangeable. | right: for (i = 0; i < n; i++) runs n times with i going up to n - 1; with <= it runs n + 1 times and reaches i = n.
M wrong rule / right ruleWholeArrayArithmetic: wrong: a = a + b adds the arrays element by element. | right: Java has no arithmetic on whole arrays; write a loop that adds a[i] + b[i] for each i.
M wrong rule / right ruleIdiomOverridesCode: wrong: An array loop processes the whole array from index 0 to length-1 and increments its index at the end of the body, whatever the code says. | right: The loop visits exactly the indices that its initialisation, guard and update produce, in the order in which its statements are written.
M wrong rule / right ruleElementBoundToOldIndex: wrong: After i changes, X[i] still refers to the element at the old value of i. | right: a[i] is evaluated with the current value of i each time it is used.
M wrong rule / right ruleArrayUseScansAllCells: wrong: Using an array means every cell must be scanned. | right: A traversal may cover only part of the array or stop early (as in a search); indexing reaches single elements directly.
T uneven-application rulePoints to LT: initialize i, test, run the body with the current i, update, test again. Inconsistent application: on some passes the update is applied before the body, or a[i] is traced with the previous i.
N identity ruleIdentity: a traversal is a loop that steps an index through the array and performs the same operation on each element it visits.
S declarative ruleDeclarative: the canonical traversal is 'for (int i = 0; i < a.length; i++) { ... a[i] ... }', which gives i every valid index exactly once, in increasing order; the for loop is equivalent to initialize; while (test) { body; increment; }.
LT operational sequencing ruleSequencing: i = 0; test i < a.length; body using a[i]; i++; test; ... When i == a.length the test fails and the body is not executed, so a[a.length] is never touched.
OP evaluation / result ruleResult: the body runs a.length times, and the result depends on the body. Squaring each element of {1, 2, 3, 4, 5} leaves {1, 4, 9, 16, 25}; summing leaves the total in the accumulator.
OS state-transition ruleState transition: one pass applies the body to element i (reading or writing a[i] and possibly updating an accumulator), then i increases by 1; no other element is touched unless the body indexes it.
R composition rule (with a neighbour)with indexing: The loop variable is used as the index, so a[i] reaches a different element on each pass.
R composition rule (with a neighbour)with enhanced_for: for (int x : a) is a traversal that hands the body each value a[i] and hides the index i.
R composition rule (with a neighbour)with for_loop: for (int i = 0; i < a.length; i++) gives i every valid index exactly once, in increasing order; the bound must be < a.length, not <=.
R composition rule (with a neighbour)with boolean_flag_array: The sieve traverses isPrime[] once to set every flag to true and again at the end to count the flags still true.
R composition rule (with a neighbour)with array_reversal: Reversal traverses only the first half (i < N/2), exchanging each a[i] with its mirror a[N-1-i].
R composition rule (with a neighbour)with function_plotting: Sample points are computed into x[] and y[] by one traversal and drawn by another.
R composition rule (with a neighbour)with running_extreme: The running maximum is found in one traversal that keeps the largest value seen so far, starting from Double.NEGATIVE_INFINITY.
P plan / role rulePlan/role: the index is a stepper, and the loop carries out a Soloway-style plan (accumulate/sum with a gatherer, count, search, find the extreme, copy) once for each element.
C conservation ruleConservation: running the index downward (a.length-1 to 0) visits the same set of elements in reverse order, harmless for a sum but not for a shift. Starting at 1 or stopping at a.length-1 drops an element. Invariant: before pass i, elements 0..i-1 have been processed.
D error rulerule broken: A result that depends on all elements is known only after the loop ends. (silent logic error)
D error rulerule broken: The guard must be i < a.length. (run-time exception)
D error rulerule broken: The traversal must cover every element it is meant to process. (silent logic error)
D error rulerule broken: Arithmetic operators do not apply to whole arrays. (compile-time)
X applicability ruleApplicability: use an index traversal when every element (or a contiguous range) must be processed and the index matters (writing a[i], comparing neighbours, reporting positions). Use enhanced for when only the values matter, and stop early when one element settles the answer (search).

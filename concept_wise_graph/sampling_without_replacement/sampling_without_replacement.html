Rules of the concept (14)

Book (SW-1e, p. 93 (pdf 103)): “In many situations, we want to draw a random sample from a set such that each member of the set appears at most once in the sample.”
Book (SW-1.4, p. 93 (pdf 103)): “each member of the set appears at most once in the sample.”
Rule typeRule
E folk-meaning ruleFolk meaning: 'pick M random items' is read as M independent random picks, so repeats seem acceptable. Rule: in sampling without replacement each member of the set appears at most once, like lottery balls not put back.
M wrong rule / right ruleSampleMayRepeat: wrong: A sample drawn without replacement may contain the same item twice. | right: Each member of the set appears at most once in the sample.
T uneven-application rulePoints to LT: perm[] is first filled with 0..N-1, then the first M shuffle passes run, then perm[0..M-1] is printed. Inconsistent application: the sample is read before all M exchanges are done, or the identity fill is skipped on a trace.
N identity ruleIdentity: sampling without replacement draws a random sample of M items from N in which no item can be chosen twice.
S declarative ruleDeclarative (Program 1.4.1): perm[j] = j for all j; for i < M, r = i + (int) (Math.random() * (N-i)) and exchange perm[i] with perm[r]; perm[0..M-1] is the sample.
LT operational sequencing ruleSequencing: read M and N, create perm, fill it with the identity, run M exchange passes left to right, then print perm[0] .. perm[M-1].
OP evaluation / result ruleResult: M distinct integers from 0..N-1 (e.g. java Sample 6 16 prints 9 5 13 1 11 8). If M == N the result is a random permutation; if M > N the program throws ArrayIndexOutOfBoundsException.
OS state-transition ruleState transition: each pass exchanges perm[i] with one element to its right, fixing perm[i] as the next sampled item; perm stays a permutation of 0..N-1.
R composition rule (with a neighbour)with shuffle: The sample is the first M passes of the shuffle applied to the identity permutation.
P plan / role rulePlan/role: draw lottery numbers or deal a hand. The permutation can also serve as indices into another array (deck[perm[i]]) to sample it without rearranging it.
C conservation ruleConservation: perm remains a permutation of 0..N-1 after every exchange, so no value can appear twice for any M <= N; changing M changes only how many passes run.
D error rulerule broken: The sample size cannot exceed the population size. (run-time exception)
D error rulerule broken: Each pick must come from the items not yet sampled. (silent logic error)
X applicability ruleApplicability: use it when the sample must contain distinct items (lotteries, card hands, survey samples). When repeats are allowed (sampling with replacement), independent random indices are simpler.

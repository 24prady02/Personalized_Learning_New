Rules of the concept (15)

Book (SW-1e, p. 19 (pdf 29)): “For literals tab, newline, backslash, single quote and double quote, we use the special escape sequences”
Book (SW-1.3, p. 78 (pdf 88)): “Use tabs ('\t' characters) to line up columns.”
Rule typeRule
E folk-meaning ruleIn everyday text a backslash is just a character, and a new line is made by pressing Enter. Inside a Java literal a backslash starts an escape: \n is one newline character and \\ is one backslash, and a literal cannot contain a raw line break.
M wrong rule / right ruleEscapeIsTwoCharacters: wrong: \t in a string prints a backslash and the letter t. | right: A backslash starts an escape sequence, so \t is a single tab character.
T uneven-application rulePoints to LT (the compiler turns each escape into a single character). Applied unevenly, a student prints "\n" as a line break but counts it as two characters in length() or charAt.
N identity ruleEscape sequence: a backslash code inside a char or String literal that stands for one special character (\t, \n, \\, \', \").
S declarative ruleJava has eight escape sequences. The common ones are \t (tab), \n (newline), \\ (backslash), \' (single quote) and \" (double quote), and each represents a single character.
LT operational sequencing ruleThe compiler replaces each escape with its single character while reading the literal, so at run time the String already contains that one character.
OP evaluation / result ruleSystem.out.print("Hello!\nHow are you doing?\n") prints two lines. "a\tb" prints a, a tab, then b. "Hi\n".length() is 3.
OS state-transition ruleAn escape changes no variable. Printing \n moves the output position to the start of a new line.
R composition rule (with a neighbour)with string_literal: Escapes are written inside "..." or '...'. \" puts a double quote inside a String literal without ending it.
P plan / role ruleEscapes format output (line breaks, tab-aligned columns) and put quote or backslash characters into text.
C conservation ruleRemoving the backslash turns \n into the letter n. Doubling it (\\n) prints a backslash followed by n. Adding a space after \n puts a space at the start of the next line.
D error rulerule broken: A double quote inside a String literal must be escaped. (compile-time)
D error rulerule broken: A backslash must be followed by a valid escape character. (compile-time)
D error rulerule broken: A backslash followed by a valid escape letter is replaced by that character. (silent logic error)
X applicability ruleUse escapes for special characters inside literals. For line ends in formatted output, use println or printf's %n, which gives the platform line separator.

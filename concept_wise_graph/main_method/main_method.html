Rules of the concept (15)

Book (SW-1e, p. 7 (pdf 17)): “When you type java followed by a class name in your terminal application, the system calls the main() method that you defined in that class”
Book (OT-Hello, ): “In the Java programming language, every application must contain a main method whose signature is: public static void main(String[] args)”
Book (OT-Hello, ): “The main method accepts a single argument: an array of elements of type String.”
Book (JLS-12.1, ): “The Java Virtual Machine starts execution by invoking the method main of some specified class, passing it a single argument, which is an array of strings.”
Rule typeRule
E folk-meaning ruleEveryday reading: 'main' sounds like the most important part, and 'void' like empty or invalid. Java rule: main is the entry point that java Name calls; public static void main(String[] args) must be written exactly, and void only means main returns no value.
T uneven-application ruleApplies the entry-point rule (LT) unevenly: starts tracing at the top of the file on one trace and at main on another, or stops before main's last statement.
N identity rulemain is the method that is the entry point of a Java program: public static void main(String[] args) { statements }.
S declarative ruleThe header must be public static void main(String[] args); the keywords are required; its body is a sequence of statements in braces, each followed by a semicolon.
LT operational sequencing ruleWhen the program runs, it starts at the first statement in main and ends when it finishes the last statement, executing the statements in order, one by one.
OP evaluation / result rulemain returns no value (void); the program's observable result is whatever main's statements print.
OS state-transition ruleCalling main binds args to the array of command-line strings and then runs its body; when its last statement finishes, control goes back to the system.
R composition rule (with a neighbour)with class_declaration: main is declared inside the class's braces; java Name looks in class Name for main.
R composition rule (with a neighbour)with statement: main's body holds the statements; running the program executes them in order, one by one.
R composition rule (with a neighbour)with command_line_args: The command-line arguments arrive in main's parameter args, an array of Strings (args[0], args[1], ...).
P plan / role rulePurpose: the single place where a Chapter 1 program's work is written; programming at this stage means specifying a class name and the sequence of statements in its main().
C conservation ruleChanging the order of main's statements changes the order of output; changing public static void main(String[] args) (e.g. dropping static or args) keeps it compiling but leaves the class without a launchable entry point, or breaks compilation if misspelt.
D error rulerule broken: main is written public static void main(String[] args) (launch error)
D error rulerule broken: public, static, void and main must be present and correctly spelled (compile-time)
X applicability ruleEvery runnable program needs exactly this main; put Chapter 1 code in it. It is not the place for code that should be reused or tested separately (that needs other methods, Section 2.1).

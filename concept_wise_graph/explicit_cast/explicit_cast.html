Rule typeRule
E folk-meaning ruleFolk meaning: 'convert 2.7 to a whole number' means round it to 3, and (int) looks like a function label that applies to everything written after it. Java rule: a cast to int truncates toward zero ((int) 2.7 is 2) and, having higher precedence than arithmetic, applies only to the value immediately following it.
M wrong rule / right ruleCastAfterIntDivision: wrong: (double) (3 / 5) is 0.6. | right: The integer division 3 / 5 = 0 happens inside the parentheses before the cast, so the result is 0.0; write (double) 3 / 5 to get 0.6.
M wrong rule / right ruleCastAppliesToWholeExpression: wrong: (int) 2.5 / 0.15 casts the whole quotient to int. | right: The cast applies only to what comes right after it, here 2.5, so the expression is 2 / 0.15 (a double); write (int) (2.5 / 0.15) to cast the quotient.
M wrong rule / right ruleCastParsesString: wrong: (int) args[0] converts the text "34" into the number 34. | right: A cast cannot convert a String; a String argument that represents a number must be converted with a method such as Integer.parseInt.
M wrong rule / right ruleCastRounds: wrong: (int) 2.7 evaluates to 3. | right: A cast to int discards the fractional part (rounds toward zero, so (int) -2.7 is -2); Math.round rounds to the nearest integer.
M wrong rule / right ruleLaterDoubleLiteralFixesDivision: wrong: Changing a later literal to 100.0 fixes an earlier int division. | right: The int division happens first, when its own operands are both ints; a double must appear in that division itself (or one operand must be cast before it).
T uneven-application rulePoints to LT (the cast is a unary operator applied to the operand right after it, before * and /). Applied unevenly: in one line the student casts only the first operand, and in another applies the same cast to the whole expression.
N identity ruleA cast is a unary operator, written (type) expression, that converts a value of one primitive type to another, used when the conversion may lose information.
S declarative rule(T) e converts the value of e to type T; a double-to-int cast discards the fraction by rounding toward zero; a cast is required for narrowing conversions; it has higher precedence than arithmetic; casts between boolean and numbers, or from String to int, are not allowed.
LT operational sequencing ruleEvaluate the operand immediately to the right of the cast (a parenthesized expression is evaluated completely first), convert that value, then continue with the remaining operators of the expression.
OP evaluation / result rule(int) 2.71828 is int 2; (int) -2.7 is -2; (int) 11 * 0.3 is double 3.3; (int) (11 * 0.3) is int 3; (double) 3 / 5 is 0.6 but (double) (3 / 5) is 0.0; (char) ('a' + 4) is 'e'.
OS state-transition ruleA cast yields a new value and changes nothing else: neither the type nor the value of the variable being cast changes (after int x = (int) pi; pi is still 3.14159).
R composition rule (with a neighbour)with type_conversion: A cast is the explicit conversion between primitive types, needed exactly where automatic conversion is refused because information may be lost.
R composition rule (with a neighbour)with math_random: To turn Math.random()'s double into a random int from 0 to N-1, the cast must enclose the product: (int) (Math.random() * N); casting first gives 0.

P plan / role ruleUsed to discard information on purpose: truncating a scaled random number to an index, taking the integer part, converting between char and int codes ((char) ('a' + k)), or forcing real division with (double) sum / n.
C conservation ruleMoving the parentheses changes when truncation happens ((int) (a * b) vs (int) a * b); removing a cast from a narrowing assignment turns it into a compile-time error; int to double to int restores the value, but double to int to double loses the fraction.

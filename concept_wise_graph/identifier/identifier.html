Rule typeRule
E folk-meaning ruleIn English, Total, total and TOTAL are the same word, and names may contain spaces or hyphens (max-value). Java identifiers are case-sensitive and may use only letters, digits, _ and $, so total and Total are different names and max-value is a subtraction.
M wrong rule / right ruleIdentifierCaseInsensitive: wrong: System.out.Println and System.out.println name the same method. | right: Java is case-sensitive: names of variables, methods and classes that differ only in capitalization are different names.
M wrong rule / right ruleNoReservedWords: wrong: keywords may be reused as identifiers | right: Keywords are reserved by Java and cannot be used as variable names.
T uneven-application rulePoints to LT (a name refers to the declaration with exactly that spelling in scope). Applied unevenly, a student treats Count and count as one variable in one statement but as two in another.
N identity ruleIdentifier: a name for a variable, method or class, made of letters, digits, _ and $ and not starting with a digit.
S declarative ruleAn identifier is a sequence of letters, digits, _ and $ whose first character is not a digit. Identifiers are case-sensitive, and reserved words such as int, public or class cannot be used.
LT operational sequencing ruleWhen an identifier appears, the compiler looks it up by exact spelling among the declarations in scope (an error if none matches). At run time a variable's name is replaced by that variable's current value.
OP evaluation / result ruleAn identifier used as an expression yields the current value of the variable it names, with that variable's declared type. abc, Ab$, abc123 and a_b are legal names; Ab*, 1abc and a+b are not.
OS state-transition ruleA name does nothing at run time. Only an assignment (or ++ or op=) with the name on its left changes the variable it names.
R composition rule (with a neighbour)with variable: Each variable is named by one identifier, which must be unique within its scope: declaring a second local with the same name in that scope is a compile error.
R composition rule (with a neighbour)with declaration: A declaration binds the identifier to a type. Every later use must repeat exactly that spelling, or the compiler cannot resolve it.
P plan / role ruleIdentifiers let code refer to values and code by name. Descriptive names make each variable's role readable to people, though names have no effect on what the program computes.
C conservation ruleRenaming an identifier consistently at its declaration and every use leaves behavior unchanged. Renaming only some occurrences, or changing only the capitalization, breaks compilation with 'cannot find symbol'.
D error rulerule broken: Identifiers are case-sensitive and must match a declaration exactly; a name that matches nothing in scope cannot be resolved. (compile-time)
D error rulerule broken: Every variable must be declared (with a type) before use and referred to by exactly the declared name, inside its scope. (compile-time)
D error rulerule broken: Reserved words cannot be used as identifiers. (compile-time)
D error rulerule broken: An identifier may not start with a digit or contain spaces or operator symbols. (compile-time)
X applicability ruleEvery variable, method and class needs an identifier. Pick descriptive lowerCamelCase names, and use single letters only for short-lived loop indices or standard maths symbols. A name never stands in for a value; only literals and expressions do that.

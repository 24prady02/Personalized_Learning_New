Rules of the concept (13)

Book (SW-1e, p. 134 (pdf 144)): “For many common tasks, it is convenient to think of each program as a filter that converts a standard input stream to a standard output stream in some way”
Book (SW-1.5, p. 134 (pdf 144)): “to think of each program as a filter that converts a standard input stream”
Rule typeRule
E folk-meaning ruleAn everyday filter (a coffee filter) removes things. In the UNIX sense a filter is any program that reads standard input and writes standard output, even one that removes nothing.
M wrong rule / right ruleRedirectionIsArgument: wrong: The file a filter processes shows up in args[]. | right: A filter reads only standard input. The file or upstream program is attached by < or |, and args[] carries only parameters such as lo and hi.
T uneven-application rulePoints to LT (read one value, test it, maybe print it, repeat). An uneven trace prints out-of-range values on some passes, or holds all the output until the end.
N identity ruleA filter is a program that converts a standard input stream into a standard output stream.
S declarative ruleA filter reads from standard input and writes to standard output, classically writing a subsequence of its input (e.g. RangeFilter keeps the values between lo and hi).
LT operational sequencing ruleEach pass of while (!StdIn.isEmpty()) reads one value t, tests lo <= t <= hi, and prints t right away if the test passes. Output is produced while input is still being read.
OP evaluation / result rule`java RangeFilter 100 400` with input 358 1330 55 165 689 1014 3066 387 575 843 203 48 292 877 65 998 prints 358 165 387 203 292: the in-range values, in their original order.
OS state-transition ruleOne pass reads one value and appends it to the output only if it passes the test. lo and hi do not change.
R composition rule (with a neighbour)with piping: Piping connects filters: the output of one becomes the input of the next, so filters compose into pipelines (`java RandomSeq 1000 | more`).
P plan / role rulePlan: the stream filter, a one-pass read-test-print loop that uses only a fixed number of variables. The value read is a most-recent holder and lo and hi are fixed values.
C conservation ruleA filter keeps the relative order of the values it passes (it outputs a subsequence). Filters can be chained in any number without changing each other.
D error rulerule broken: Every value must pass the range test before it is output or processed. (silent logic error)
X applicability ruleA filter is the right tool when each output depends only on the current value, or on a fixed amount of state. Tasks that need all the values (sorting, k-th smallest, percentage above the mean) must store them in an array first.

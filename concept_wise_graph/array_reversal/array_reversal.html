Rules of the concept (17)

Book (SW-1e, p. 113 (pdf 123)): “Write a code fragment that reverses the order of a one-dimensional array a[] of String values.”
Book (SW-1e, p. 113 (pdf 123)): “Do not create another array to hold the result.”
Book (SW-1.4, ): “reverses the order of values in a one-dimensional string array. Do not create another array to hold the result.”
Rule typeRule
E folk-meaning ruleFolk meaning: 'reverse every element' suggests one swap per position, so the loop runs over all n positions. Java rule: each exchange moves two elements, so n/2 exchanges (i < N/2) reverse the array, and n exchanges reverse it twice, restoring the original.
M wrong rule / right ruleOffByOneBound: wrong: < vs <= and 0..n vs 0..n-1 are interchangeable. | right: The mirror of a[i] is a[N-1-i] (not a[N-i]), and the loop runs while i < N/2.
M wrong rule / right ruleReverseFullLength: wrong: Reversing an array needs a swap for every one of the n positions. | right: Swapping for i < n/2 is enough; going to n undoes the reversal.
T uneven-application rulePoints to LT: for i from 0 while i < N/2, save a[i] in temp, copy a[N-1-i] to a[i], and copy temp to a[N-1-i]. Inconsistent application: the trace exchanges a mirror pair on some passes but only copies one way on others, or computes the mirror with an updated i.
N identity ruleIdentity: in-place reversal rearranges an array so that a[i] and a[N-1-i] trade places for every i, without a second array.
S declarative ruleDeclarative: for (int i = 0; i < N/2; i++) { temp = b[i]; b[i] = b[N-1-i]; b[N-1-i] = temp; }.
LT operational sequencing ruleSequencing: pass i exchanges the i-th pair from the outside in: (0, N-1), (1, N-2), ... For odd N the middle element is never touched, because N/2 rounds down.
OP evaluation / result ruleResult: {1, 2, 3, 4, 5} becomes {5, 4, 3, 2, 1} with the same length and the same values.
OS state-transition ruleState transition: each pass changes exactly two elements, a[i] and a[N-1-i] (plus temp); other elements and N are unchanged.
R composition rule (with a neighbour)with array_exchange: Reversal is a loop of exchanges a[i] <-> a[N-1-i], so it inherits the exchange idiom and its temporary variable.
R composition rule (with a neighbour)with array_traversal: Reversal traverses only the first half (i < N/2) while indexing the second half through the mirror index.
P plan / role rulePlan/role: a two-ended mirror-swap plan in which the array plays the role of an organizer, its elements rearranged in place.
C conservation ruleConservation: the multiset of values is preserved (only exchanges are used). Reversal is its own inverse: reversing twice, or running the loop to N instead of N/2, gives back the original order.
D error rulerule broken: Only the first half is traversed. (silent logic error)
D error rulerule broken: The mirror index is N-1-i. (run-time exception)
D error rulerule broken: The exchange needs a temporary variable. (silent logic error)
X applicability ruleApplicability: reverse in place when the original order is no longer needed and memory matters. When the original must be kept, copy into a new array (b[N-1-i] = a[i]) or just traverse backwards.

Rules of the concept (18)

Book (SW-1e, p. 166 (pdf 176)): “The key to the computation is the random move, which is specified by the transition matrix.”
Book (SW-1e, p. 166 (pdf 176)): “The variable sum tracks the endpoints of the intervals defined in row p[page], and the for loop finds the interval containing the random value r.”
Book (SW-1.6, p. 164 (pdf 174)): “each row represents a discrete probability distribution”
Book (SW-1.6, p. 164 (pdf 174)): “the entry in row i and column j is the probability that the random surfer moves to page j when on page i”
Rule typeRule
E folk-meaning ruleEveryday "random" means every outcome equally likely, which is what Math.random() gives; the random move must instead pick page j with the unequal probability p[page][j].
M wrong rule / right ruleCumulativeOffByOne: wrong: The cumulative-probability boundary test is inclusive/exclusive interchangeably. | right: Add p[page][j] to sum first and then test r < sum; sum is the right endpoint of interval j, so r lands in interval j with probability equal to its length.
T uneven-application ruleApplies LT (r drawn once; for each j: add p[page][j] to sum, then test r < sum) unevenly: e.g. testing before adding on some passes, or drawing a new r for each j.
N identity ruleAn algorithm: generating a random integer from a discrete distribution (row p[page]) by locating a uniform random number in cumulative intervals.
S declarative ruleThink of row p[page] as N intervals of (0, 1) whose lengths are the probabilities; a uniform r from Math.random() falls into interval j with probability p[page][j], and the surfer moves to j.
LT operational sequencing ruler = Math.random() is drawn once; sum = 0.0; j goes 0, 1, ...; on each pass sum += p[page][j] and then if (r < sum) set page = j and break, so the first interval whose right end exceeds r wins.
OP evaluation / result ruleReturns (through page) one integer 0..N-1; at page 4 of tiny.txt sum takes 0.47, 0.49, 0.96, ... and r = .71 gives page 2.
OS state-transition ruleOne move changes page from its current value to j (and leaves freq and p unchanged); the locals r, sum and j live only for that move.
R composition rule (with a neighbour)with transition_matrix: Reads exactly one row p[page]; the row must sum to 1, otherwise r can exceed the final sum and no j is chosen.
R composition rule (with a neighbour)with simulation_loop: Each move starts from the page the previous move produced, and the simulation repeats it T times; the next row used is p[new page].
R composition rule (with a neighbour)with boolean_expression: The relational test r < sum decides both the chosen page and the early break; < (not <=) matches the half-open interval endpoint tracked by sum.
R composition rule (with a neighbour)with math_library: Math.random() supplies one uniform double in [0, 1) per move; it must be called once before the j loop, not inside it.
P plan / role ruleSampling plan (search the cumulative sums): sum is a gatherer, j a stepper, and page a most-recent holder of the current location; break ends the search as soon as the interval is found.
C conservation ruleChanging the search (linear to binary) or the order of pages keeps the distribution of outcomes; replacing r < sum with r <= sum changes it only on a zero-probability event; moving Math.random() into the loop breaks it.
D error rulerule broken: Add the entry to sum before testing r < sum. (silent logic error)
D error rulerule broken: Row p[page] must sum to 1. (silent logic error)
D error rulerule broken: break must exit the search once the interval is found. (silent logic error)
X applicability ruleUse to draw from any non-uniform discrete distribution (one row of probabilities); for uniform choice Math.random() scaled is enough, and for large N a binary search over the cumulative sums is faster.

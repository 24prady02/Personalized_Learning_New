Rules of the concept (14)

Book (SW-1e, p. 23 (pdf 33)): “the literal 6.022e23 represents the number 6.022”
Book (SW-1.2, ): “with a notation like scientific notation, e.g., 6.022E23 for Avogadro's constant”
Rule typeRule
E folk-meaning ruleFolk meaning: in maths e is Euler's number 2.718..., so 6.022E23 reads as 6.022 times e to the 23rd. Java rule: inside a numeric literal, e or E means 'times ten to the power', so 6.022e23 is 6.022 x 10^23; Euler's number is Math.E and e^x is Math.exp(x).
M wrong rule / right ruleExponentIsPower: wrong: 6.022E23 means 6.022 times e to the power 23. | right: E23 means times 10 to the 23rd; e to a power is computed with Math.exp(23), and the constant e is Math.E.
T uneven-application rulePoints to LT (the literal is converted once, at compile time, to the nearest double). Applied unevenly: the student shifts the decimal point the right way for 1e6 but the wrong way for a negative exponent such as 1e-15, or treats 1e6 as an int on some lines.
N identity ruleScientific notation is a form of floating-point (double) literal: a mantissa, then e or E, then a signed integer exponent of ten.
S declarative rulemEn denotes m x 10^n and is always of type double, even when the value is whole (1e6 is 1000000.0); the exponent may be negative (1e-15).
LT operational sequencing ruleThe value is fixed at compile time; at run time the literal is just a double operand, so the usual promotion applies to the other operand of each operator it meets.
OP evaluation / result ruleType double: 6.02e23 / 2.0 is 3.01E23; 1e6 is 1000000.0; 1e-15 is 1.0E-15; println prints very large or very small doubles back in E notation.
OS state-transition ruleEvaluating the literal changes nothing; double big = 6.022e23; stores the nearest double to 6.022 x 10^23 in big.
R composition rule (with a neighbour)with literal: Scientific notation is a double literal, so the literal rules for double apply: it cannot initialize an int without a cast (int n = 1e6; does not compile).
P plan / role ruleUsed to write very large or very small fixed constants readably, e.g. Avogadro's number or a tolerance epsilon = 1e-15 (Sajaniemi role: fixed value).
C conservation ruleChanging the sign of the exponent changes the magnitude by a factor 10^(2n); replacing 1e6 by 10^6 changes the value to 12 (^ is exclusive or); replacing it by Math.pow(10, 6) keeps the value but computes it at run time.
D error rulerule broken: A power of ten is written with e-notation (or Math.pow), not with ^. (silent logic error)
D error rulerule broken: An e-notation literal is a double and cannot be stored in an int without a cast. (compile-time)
X applicability ruleUse e-notation for double constants spanning many orders of magnitude (physical constants, tolerances); for exact integers use int or long literals, and for computed powers use Math.pow.

Rules of the concept (17)

Book (SW-1e, p. 99 (pdf 109)): “To maintain that knowledge, we use an array found[], which uses the card value as an index”
Book (SW-1.4, ): “The default initial value is 0 for all numeric primitive types and false for type boolean.”
Rule typeRule
E folk-meaning ruleFolk meaning: using a value (a card number) as a position is not how everyday checklists work; people search a list to see whether they have seen something. Java rule: found[val] is the flag stored at index val, so one indexed read answers 'seen val?'.
M wrong rule / right ruleNewArrayHoldsGarbage: wrong: The slots of a new boolean[n] hold unpredictable values until assigned. | right: new boolean[n] starts every flag at false.
M wrong rule / right ruleOffByOneBound: wrong: < vs <= and 0..n vs 0..n-1 are interchangeable. | right: To use the value N itself as an index, the array must have length N+1 (new boolean[N+1]), and loops over values 2..N use i <= N.
T uneven-application rulePoints to LT: for each new value, test found[val] and, only if it is false, count it and set the flag. Inconsistent application: the flag is set before the test on some passes, so a new value is counted as already seen.
N identity ruleIdentity: a boolean array indexed by value, in which flag[v] records whether v has been seen or has a property.
S declarative ruleDeclarative: create boolean[] flags = new boolean[N] (all false); mark v with flags[v] = true; test with if (!flags[v]). Values must lie in 0..N-1.
LT operational sequencing ruleSequencing (CouponCollector): generate val, increment cardcnt, test found[val], and if it is false increment valcnt and set found[val] = true; repeat while valcnt < N.
OP evaluation / result ruleResult: the count derived from the flags, e.g. CouponCollector prints the number of cards drawn, and PrimeSieve 25 prints 9; at the end of the collector found[] is all true.
OS state-transition ruleState transition: one step sets at most one flag from false to true and never back, so each element is a one-way flag.
R composition rule (with a neighbour)with array_default_values: new boolean[n] starts every flag at false, which CouponCollector relies on; PrimeSieve needs true and so sets it with a loop.
R composition rule (with a neighbour)with array_traversal: The sieve traverses isPrime[] to set every flag to true and later traverses it again to count the flags still true.
P plan / role rulePlan/role: set membership by direct indexing. Each element is a one-way flag (Sajaniemi), and the array lets data index into the array, turning 'have I seen v?' into one step.
C conservation ruleConservation: in CouponCollector, valcnt always equals the number of true entries in found[]. Enlarging the value range requires enlarging the array (N+1 when N itself is an index).
D error rulerule broken: Values used as indices must lie in 0..length-1. (run-time exception)
D error rulerule broken: A start value other than false must be set explicitly. (silent logic error)
D error rulerule broken: Test the flag before setting it. (silent logic error)
X applicability ruleApplicability: use a flag array when the values are small non-negative integers (card values, numbers up to N) and memory for N flags is affordable. Do not use one for huge, negative or non-integer keys.

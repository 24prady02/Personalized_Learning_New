Rules of the concept (16)

Book (SW-1e, p. 91 (pdf 101)): “When we have a small number of literal values that we want to keep in array, we can declare and initialize it by listing the values between curly braces, separated by commas.”
Book (OT-Arrays, ): “Here the length of the array is determined by the number of values provided between braces and separated by commas.”
Book (SW-1.4, ): “we can initialize it by listing the values between curly braces, separated by a comma.”
Rule typeRule
E folk-meaning ruleFolk meaning: in maths, braces {1, 2, 3} denote a set (unordered, no repeats) and brackets [1, 2, 3] a list, so novices write int[] a = [1, 2, 3] or expect {1, 1, 2} to have 2 elements. Java rule: braces enclose an ordered, comma-separated list whose count (repeats included) is the length.
M wrong rule / right ruleArrayInitializerContentsInBrackets: wrong: Initializer values go in [] instead of {}. | right: Starting values go in braces, as in int[] a = {v0, v1};; brackets only mark the type or an index.
M wrong rule / right ruleArrayBracketCountIsLength: wrong: The number of brackets in an array type or initializer is the array's length. | right: Brackets give the number of dimensions; an initializer's length is the number of values between its braces.
T uneven-application rulePoints to LT: an array of length k+1 is created, then v0..vk are stored at indices 0..k in order. Inconsistent application: the trace puts the first value at index 1 for one initializer but at index 0 for another, or counts the length differently.
N identity ruleIdentity: an array initializer is a brace-enclosed, comma-separated list of values that creates and fills an array in one step.
S declarative ruleDeclarative: 'T[] a = {v0, ..., vk};' declares, creates (no new needed) and initializes an array of length k+1. For 2-D arrays each row is its own brace list. The bare form is legal only in a declaration; elsewhere write new T[]{...}.
LT operational sequencing ruleSequencing: the array of length k+1 is created, the initializer expressions are evaluated left to right and stored in a[0], a[1], ..., a[k], and then the reference is assigned to a.
OP evaluation / result ruleResult: int[] a = {1, 2, 3}; gives a.length == 3, a[0] == 1, a[2] == 3. String[] suit = {"Clubs", "Diamonds", "Hearts", "Spades"}; gives suit.length == 4.
OS state-transition ruleState transition: one execution creates one array holding the listed values and sets the variable to its reference.
R composition rule (with a neighbour)with array_creation: An initializer implies array creation: it is shorthand for new T[k+1] followed by k+1 element assignments, so new is not written.
P plan / role rulePlan/role: build small fixed tables of constants known when the program is written (suits, ranks, month names), usually used as fixed-value lookup tables.
C conservation ruleConservation: adding or removing a value changes the length. Code that uses a.length (e.g. rank.length) adapts, while code with a hard-coded size breaks. Reordering values changes which index holds which value.
D error rulerule broken: Initializer values are enclosed in braces. (compile-time)
D error rulerule broken: The bare {...} form is allowed only in a declaration. (compile-time)
D error rulerule broken: Each value must be assignable to the element type. (compile-time)
X applicability ruleApplicability: use an initializer when all values are known at compile time and the array is small. When the values must be computed at run time, create the array with new and fill it in a loop.

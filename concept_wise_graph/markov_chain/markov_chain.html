Rule typeRule
E folk-meaning ruleEveryday "chain" of events suggests the whole history matters; in a Markov chain the next state depends only on the current state, through that state's row of the transition matrix.
M wrong rule / right ruleStartPageMatters: wrong: The page ranks depend on which page the surfer starts from. | right: For the random-surfer chain the long-run probabilities are the same for all starting pages (basic limit theorem); that is why RandomSurfer can start at page 0.
T uneven-application ruleApplies LT (each step uses the row of the current state) unevenly: e.g. on some steps using the starting page's row instead of the current page's row.
N identity ruleA mathematical model: a random process on states (pages) whose moves are given by a transition matrix.
S declarative ruleThe surfer's random process is a Markov chain; by the basic limit theorem the probability of eventually ending on any page is the same for all starting pages (mixing), though not all chains mix.
LT operational sequencing ruleState sequence: from the current page i, choose the next page j with probability p[i][j]; repeat from j. In probability form, the t-step distribution is the (t-1)-step distribution times the matrix.
OP evaluation / result ruleProduces the stationary probabilities (page ranks): for tiny.txt about .27 .27 .15 .25 .07.
OS state-transition ruleOne step moves the state from page i to a page j drawn from row i; in matrix form, one multiplication turns the distribution after t-1 moves into the distribution after t moves.
R composition rule (with a neighbour)with transition_matrix: The chain is defined by the matrix: it must be square with every row a probability distribution.
R composition rule (with a neighbour)with power_method: Each vector-matrix multiplication advances the chain's probabilities by one move; repeating it approaches the stationary vector.
P plan / role ruleModel a memoryless random process to compute its long-run behaviour (page ranks) instead of following one surfer.
C conservation ruleChanging the start state keeps the limiting distribution (if the chain mixes); removing the random leap can break mixing; squaring the matrix gives two-step probabilities.
D error rulerule broken: Each row must be a probability distribution. (silent logic error)
D error rulerule broken: The chain must mix for start-independent ranks. (silent logic error)
X applicability ruleRight model when the next state depends only on the current state with fixed probabilities (web surfing, many random processes); its limit theorem gives start-independent results only for chains that mix.

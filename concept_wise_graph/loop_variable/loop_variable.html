Rules of the concept (20)

Book (SW-1e, p. 56 (pdf 66)): “in a typical for loop, the incrementing variable is not available for use in later statements”
Book (SW-1.3, ): “Many loops follow the same basic scheme: initialize an index variable to some value and then use a while loop to test an exit condition.”
Rule typeRule
E folk-meaning ruleFolk meaning: in maths a variable like the i in a sum ranges over all its values at once, and 'i from 1 to 10' is a set. A Java loop variable is one storage location holding one value at a time, changed step by step by the update.
M wrong rule / right ruleLoopVariableLifetimeScope: wrong: The for variable i is a new variable on every pass rather than one variable changed by the update. | right: The for variable i is created once by the init, the update changes that same variable on every pass, and i exists only until the end of the for statement.
M wrong rule / right ruleDoubleLoopIndexCount: wrong: for (double x = 0.0; x <= 1.0; x += 0.1) runs exactly 11 times. | right: Using a double as a for-loop index is legal but bad practice: the number of iterations depends on an equality test between double values, which may not give the result you expect.
M wrong rule / right ruleForInitRepeats: wrong: The initialization of a for loop runs again after a pass of the body. | right: The initialization runs exactly once, before the first condition test.
M wrong rule / right ruleLoopUpdateChangesDirection: wrong: The update of the loop variable can change from pass to pass (e.g. switch direction) although the code is the same. | right: The update expression is the same on every pass; the loop variable changes by the rule written in the update.
M wrong rule / right ruleBodyChangeIgnoredByCondition: wrong: Changing the loop variable inside the body does not affect the loop condition; the loop still runs its planned number of times. | right: The condition is tested with the current value of the variable, including changes made in the body.
M wrong rule / right ruleLoopOutputSameEachPass: wrong: A loop prints the same thing on every pass; the changing loop variable does not affect what the body does. | right: The body uses the current value of the loop variable, so its output can differ on each pass.
M wrong rule / right ruleLoopVariableLimitsValues: wrong: The range of the loop variable limits the values that can be read or printed inside the loop. | right: The loop variable only counts passes; other values read or printed in the body are not bounded by it.
T uneven-application ruleApplies the init-test-update rule (LT, loop_control) unevenly to the loop variable: forgets one update, applies a different step on some passes, or re-initializes it mid-loop.
N identity ruleA loop variable (loop-control counter, index) is a variable that is initialized, tested and updated in order to control a loop.
S declarative ruleThe loop variable is set once by the initialization, tested by the continuation condition before each pass and updated (usually incremented) at the end of each pass; declared in a for header, it is not available after the loop.
LT operational sequencing ruleIts value is set by the init, read by the test, read by the body, then changed by the update, and the cycle repeats; the body sees the value set by the previous update.
OP evaluation / result ruleAcross passes the loop variable takes a predictable sequence of values, e.g. 4, 5, ..., 10 in TenHellos, and after a while loop it holds the first value that failed the test (11).
OS state-transition ruleOne update changes only the loop variable (i = i + 1 turns 4 into 5); one test reads it and yields true or false; an assignment to it in the body changes what the next test sees.
R composition rule (with a neighbour)with loop_control: The init, condition and update all act on the loop variable: the init sets it, the condition tests it, the update changes it.
R composition rule (with a neighbour)with while_loop: In a while loop the loop variable is declared and initialized before the loop and updated inside the body, so it remains available after the loop.
P plan / role ruleRole: stepper - a variable stepping through a systematic, predictable succession of values; it counts passes and often serves as an index.
C conservation ruleShifting the start and the bound by the same amount keeps the number of passes but changes the values the body sees; assigning to the loop variable inside the body changes the pass count.
D error rulerule broken: Update the loop variable only in the update part (or in one place in a while body). (silent logic error)
X applicability ruleUse a dedicated loop variable (int) when passes are counted or indexed; do not use a double loop variable, and do not reuse it for other roles inside the body.

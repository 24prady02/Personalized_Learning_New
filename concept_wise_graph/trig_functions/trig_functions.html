Rules of the concept (13)

Book (SW-1e, p. 44 (pdf 54)): “Note that this equation uses degrees, whereas Java's trigonometric functions use radians.”
Book (SW-1.2, ): “trigonometric functions in the Math library, such as Math.sin(), Math.cos(), and Math.toRadians()”
Rule typeRule
E folk-meaning ruleFolk meaning: from school and calculators in degree mode, sin 30 means the sine of 30 degrees (0.5). Java rule: Math.sin, Math.cos and Math.tan take their argument in radians, so Math.sin(30) is about -0.988; use Math.sin(Math.toRadians(30)).
M wrong rule / right ruleTrigTakesDegrees: wrong: Math.sin(30) is the sine of 30 degrees. | right: Math.sin takes radians; use Math.sin(Math.toRadians(30)).
T uneven-application rulePoints to LT (convert the angle to radians, then apply the function). Applied unevenly: in one program the student converts the angle before one call (Math.cos(Math.toRadians(x1))) but passes degrees directly to another (Math.sin(x2)).
N identity ruleThe trigonometric functions are Math library methods (sin, cos, tan, and inverses asin, acos, atan, atan2) whose angles are expressed in radians.
S declarative ruledouble sin(double theta), cos, tan take theta in radians; Math.toRadians and Math.toDegrees convert; the inverse functions return radians, and Math.atan2(y, x) returns the angle of (x, y) in the range from -pi to pi.
LT operational sequencing ruleThe argument expression is evaluated first (an inner Math.toRadians(deg) call runs before the outer Math.sin), then the function is computed on that double.
OP evaluation / result ruleA double: Math.sin(Math.PI/2) is 1.0; results are approximations, so Math.sin(Math.toRadians(30)) is 0.49999999999999994 and cos^2 + sin^2 is not always exactly 1.
OS state-transition ruleA trig call changes no variable; the result exists only if stored or used, e.g. double height = Math.sin(angle);.
R composition rule (with a neighbour)with math_library: The trig functions belong to the Math API, whose note fixes the unit: angles are in radians, with toDegrees() and toRadians() for conversion.
P plan / role ruleUsed for geometry and periodic signals: polar coordinates (Math.atan2), great-circle distance, sampled sound waves (Math.sin(2*Math.PI * i * hz / sps)), and points on a circle for drawing.
C conservation ruleSwitching the input between degrees and radians changes the result completely (not just slightly); adding a full period 2*Math.PI to the argument leaves the value unchanged up to rounding.
D error rulerule broken: Java's trigonometric functions take radians. (silent logic error)
X applicability ruleUse the Math trig functions whenever angles or periodic behaviour are computed, converting degree inputs with Math.toRadians first; prefer Math.atan2(y, x) to Math.atan(y/x) when the full-circle angle is needed.

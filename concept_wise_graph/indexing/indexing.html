Rules of the concept (28)

Book (SW-1e, p. 87 (pdf 97)): “We refer to each value by putting its index in brackets after the array name.”
Book (SW-1e, p. 86 (pdf 96)): “If we have N values, we think of them as being numbered from 0 to N”
Book (OT-Arrays, ): “As shown in the preceding illustration, numbering begins with 0.”
Rule typeRule
E folk-meaning ruleFolk meaning: everyday counting starts at 1 (first = number 1), maths subscripts a_1..a_n run from 1, and f(i) with parentheses means 'apply to i'. Java rule: a[i] uses square brackets and is 0-origin, so the first element is a[0] and the last is a[a.length-1].
M wrong rule / right ruleArrayAccessWithParentheses: wrong: a(i) accesses element i of an array. | right: Array elements are selected with square brackets, a[i]; a(i) would be a call of a method named a.
M wrong rule / right ruleArrayIndexStartsAtOne: wrong: The first element of a is a[1]. | right: Numbering begins with 0; the first element is a[0].
M wrong rule / right ruleArrayRangeInclusive: wrong: new int[n] has slots 0 to n, inclusive. | right: The slots are 0 to n - 1.
M wrong rule / right ruleIndexIsValue: wrong: i and a[i] are the same thing, so the position is the stored value. | right: i is a position; a[i] is the value stored at that position.
M wrong rule / right ruleArrayElementNotVariable: wrong: An array element a[i] is not a variable, so it cannot be read into directly or used inside another index, as in a[a[i]]. | right: Each element a[i] is a variable of the element type and can be used anywhere a variable of that type can, including as an index.
M wrong rule / right ruleElementNameIsWholeArray: wrong: X[i] names the whole array, not one element. | right: The array is a (a[] in the book); a[i] is the single element at index i.
M wrong rule / right ruleElementBoundToOldIndex: wrong: After i changes, X[i] still refers to the element at the old value of i. | right: a[i] is evaluated with the current value of i each time it is executed.
M wrong rule / right ruleArrayUseScansAllCells: wrong: Using an array means every cell must be scanned. | right: Arrays allow random access: a[i] reaches one element directly, and a loop visits only the elements the task needs.
T uneven-application rulePoints to LT: in a[i], a is evaluated, then i with its current value, then the bounds check, then the element is read or written. Inconsistent application: i is updated on one line, but a later a[i] is traced with the old i.
N identity ruleIdentity: an array access expression; a[i] names the single element variable at position i of the array a refers to.
S declarative ruleDeclarative: the index is any int-valued expression in square brackets; the valid indices of an array of length n are 0 to n-1, and an access outside that range throws ArrayIndexOutOfBoundsException.
LT operational sequencing ruleSequencing: the array reference is evaluated before the index; the index expression is fully evaluated with current variable values; the bounds are checked; then the element is fetched or, on the left of =, becomes the target. In a[i] = a[j], the target a[i] is located before a[j] is read.
OP evaluation / result ruleResult: a[i] has the element type and the value currently stored at position i. For int[] a = {5, 7, 9}, a[1] is 7 and a[0] + a[2] is 14.
OS state-transition ruleState transition: reading a[i] changes nothing. a[i] = v changes only element i (i, a and all other elements are unchanged), and a[i]++ adds 1 to that one element.
R composition rule (with a neighbour)with array_creation: An element can be indexed only after the array is created, and the n given to new sets the valid indices 0..n-1.
R composition rule (with a neighbour)with array_traversal: A traversal uses the loop variable as the index, so the same expression a[i] reaches a different element on each pass.
R composition rule (with a neighbour)with array_bounds: Every index value is checked against 0 and a.length at run time; any other value throws.
R composition rule (with a neighbour)with two_dimensional_array: a[i] on a 2-D array yields row i (itself a 1-D array), and a[i][j] then indexes into that row.
R composition rule (with a neighbour)with array_exchange: The exchange reads and writes elements only through their indices: t = a[i]; a[i] = a[j]; a[j] = t.
R composition rule (with a neighbour)with lookup_table: A lookup table uses a data value as the index (months[m]), so the data must lie in 0..length-1.
P plan / role rulePlan/role: random access, reaching any element directly by its position in constant time (address plus index), so code touches only the elements it needs.
C conservation ruleConservation: changing the index expression (i to i+1 or i-1) shifts which element is touched and can leave the bounds at the ends. Writing a[a[i]] instead of a[i] uses an element value as the index, a different access entirely. Changing what is stored never changes the positions.
D error rulerule broken: The index must be in 0..a.length-1. (run-time exception)
D error rulerule broken: The index must have type int (after promotion); long or double indices are rejected. (compile-time)
D error rulerule broken: Elements are selected with brackets, not parentheses. (compile-time)
D error rulerule broken: An index is a position, not the stored value. (silent logic error)
X applicability ruleApplicability: index when you need a particular element by position, or when the position is computed from data (counts[score]++, months[m]). When every value is processed in order and the position is never needed, an enhanced for loop is simpler.

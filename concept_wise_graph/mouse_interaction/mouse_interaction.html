Rules of the concept (13)

Book (SW-1.5, ): “Our standard draw library also includes methods so that the user can interact with the window using the mouse.”
Rule typeRule
E folk-meaning ruleIn the everyday sense, 'mouse pressed' is an event the program waits for. StdDraw.mousePressed() only reports whether the button is down at the moment of the call.
M wrong rule / right ruleMouseIsEvent: wrong: StdDraw.mousePressed() waits until the user clicks. | right: mousePressed() returns immediately with true or false for that moment. To catch clicks, poll it on every frame of a loop.
T uneven-application rulePoints to LT (each frame polls mousePressed, mouseX and mouseY once). An uneven trace treats one poll as blocking, or reuses an old position on some frames.
N identity ruleMouse interaction is the StdDraw input methods mousePressed(), mouseX() and mouseY(), which report the mouse state in user coordinates.
S declarative rulemousePressed() returns whether the button is currently pressed. mouseX() and mouseY() return the latest pointer position in the current x/y scale.
LT operational sequencing ruleInside the animation loop: poll the mouse, update state from it, clear, draw, show(t). The mouse is sampled once per frame.
OP evaluation / result rulemousePressed() returns a boolean, and mouseX()/mouseY() return doubles in drawing coordinates (e.g. 0.5, 0.5 at the centre of the default canvas).
OS state-transition ruleA poll changes no state and does not wait. It returns the current mouse state.
R composition rule (with a neighbour)with animation: Mouse checks run inside the frame loop. A click shorter than one frame (show(t) pause) can be missed.
P plan / role rulePlan: polling loop. The mouse coordinates are most-recent holders updated every frame.
C conservation ruleChanging the frame pause changes how responsive the program is to clicks, but not what a click does.
D error rulerule broken: mousePressed() does not block. (silent logic error)
X applicability ruleUse mouse polling for interactive drawings and games built on StdDraw. For text dialogue, use StdIn.

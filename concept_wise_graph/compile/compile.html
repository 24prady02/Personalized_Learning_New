Rules of the concept (17)

Book (SW-1e, p. 5 (pdf 15)): “The compiler takes a file with a .java extension as input (your program) and produces a file with the same name but with a .class extension (the computer-language version).”
Book (SW-1.1, ): “Compile it by typing "javac MyProgram.java" in the terminal window.”
Rule typeRule
E folk-meaning ruleEveryday meaning: to 'compile' is to gather or put together (compile a list), and 'running' a program sounds like it starts on its own. Java rule: compiling with javac only translates Name.java into bytecode in Name.class; nothing executes until java Name is typed.
M wrong rule / right ruleCompileRunsProgram: wrong: Compiling also executes the program. | right: javac only translates Name.java into Name.class; the program runs only with java Name, and run-time errors can appear then.
M wrong rule / right ruleCompilesMeansWorks: wrong: Code that compiles is code that works. | right: Code that compiles can still have run-time errors and logic errors.
T uneven-application ruleApplies the compile rule (LT) unevenly: expects output after javac on one try but not another, or runs java Name after a failed compile as if the old Name.class reflected the new edits.
N identity ruleCompiling is translating the whole Java source file into a lower-level form (Java bytecode) before execution; javac is the Java compiler.
S declarative rulejavac Name.java takes the file Name.java as input and, if there are no compile-time errors, produces Name.class (the bytecode version) with the same name.
LT operational sequencing ruleThe compiler first reads (parses) the entire file, then translates it; it does all this before the program starts running, and only if no errors were found does it write Name.class.
OP evaluation / result ruleResult of javac Name.java: either a new file Name.class and no terminal output, or a list of error messages (file:line: message, then 'N errors') and no Name.class.
OS state-transition ruleOne compile changes only the file system: it creates or overwrites Name.class; it changes no program variable and prints no program output.
R composition rule (with a neighbour)with run: java Name loads the Name.class made by javac, so a successful compile must come before running, and edits take effect only after recompiling.
R composition rule (with a neighbour)with compile_time_error: A compile-time error stops the translation, so no Name.class is produced and there is nothing new to run.
R composition rule (with a neighbour)with program_text: javac takes the program text Name.java as input; its file name must match the public class name.
P plan / role rulePurpose: check the program against the language rules and turn it into a form the JVM can execute, once, so it can then be run repeatedly with different inputs.
C conservation ruleRecompiling the same unchanged source gives the same Name.class; any edit to the source is invisible to java Name until recompiled; adding or deleting comments or whitespace changes nothing the program does.
D error rulerule broken: Source must obey Java's syntax and type rules (compile-time)
D error rulerule broken: javac needs the .java file name (launch error)
X applicability ruleCompile after every change before running, and compile often while making small changes, so each error is found close to its cause; compiling cannot find run-time or logic errors.

Rule typeRule
E folk-meaning ruleEveryday intuition links 'bigger numbers' with a 'higher note'. In digital sound the sample amplitude (y-value) sets the volume, and the frequency of oscillation sets the pitch (doubling it raises the note an octave).
M wrong rule / right ruleAmplitudeIsPitch: wrong: Making the sample values larger raises the pitch of the note. | right: The amplitude (y-value) corresponds to the volume, and the frequency sets the pitch.
M wrong rule / right ruleAnyFrequencyPlayable: wrong: A sine wave of any frequency, e.g. 30,000 Hz, plays correctly with StdAudio. | right: At 44,100 samples per second the highest reproducible frequency is the Nyquist frequency, 22,050 Hz.
T uneven-application rulePoints to LT (compute N, allocate N+1 samples, fill a[i] = sin(2*pi*i*hz/sps), then play). An uneven trace uses i/sps on some samples and i*hz/sps on others, or plays before filling.
N identity ruleStdAudio is a booksite library for playing, saving and reading sound, which it represents as an array of samples.
S declarative ruleSound is an array of doubles between -1 and +1, sampled 44,100 times per second. StdAudio.play(double[] a) plays the sound that the array represents.
LT operational sequencing ruleN = (int) (sps * duration), a = new double[N+1], then for i = 0..N a[i] = Math.sin(2*Math.PI*i*hz/sps), then StdAudio.play(a). The samples sound in index order, 44,100 per second.
OP evaluation / result ruleTen seconds of concert A (440 Hz) needs 441,001 sample values, and each one is in [-1, 1]. play is void: its result is sound.
OS state-transition ruleplay(a) plays a.length/44,100 seconds of sound and leaves a unchanged. play(double x) plays one sample for 1/44,100 second. save writes a .wav file and read returns an array.
R composition rule (with a neighbour)with math_library: Each sample is computed with Math.sin at evenly spaced times t = i/sps. The note's frequency comes from Math.pow(2, pitch/12.0).
R composition rule (with a neighbour)with function_plotting: Sampling for sound is the same as sampling for a plot. The same array can be sent to StdDraw and to StdAudio.
P plan / role rulePlan: sample-and-play synthesis. In PlayThatTune it is driven by data: a loop reads (pitch, duration) pairs and plays each note.
C conservation ruleDoubling hz moves the note up an octave and keeps the duration. Multiplying all samples by a factor below 1 changes only the volume. Writing pitch / 12 (integer division) instead of pitch / 12.0 breaks the pitch.
D error rulerule broken: StdAudio.java must be in the working directory or on the classpath. (run-time exception)
D error rulerule broken: In the book's setup a StdAudio program should end main() with System.exit(0). (silent logic error)
D error rulerule broken: Frequencies must stay below the Nyquist frequency, 22,050 Hz. (silent logic error)
X applicability ruleUse StdAudio to synthesize or sonify sampled data (tones, tunes, signal processing). Long recordings are stored in binary .wav files, not as text streams.

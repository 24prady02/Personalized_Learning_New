Rules of the concept (15)

Book (SW-1e, p. 89 (pdf 99)): “copy to another array double[] b = new double[N]; for (int i = 0; i < N; i++) b[i] = a[i];”
Book (TJ-2e, p. 112 (pdf 134)): “If you actually want to copy the array, not just the reference, you have to create a new array and copy the elements from one to the other”
Rule typeRule
E folk-meaning ruleEveryday 'copy' (b = a, like copying a value onto paper) suggests a second, separate thing. For arrays, b = a only copies the reference; a separate copy needs a new array with each element copied.
M wrong rule / right ruleAssignmentCopiesObject: wrong: Assigning an array reference copies the array. | right: b = a copies only the reference, so a and b refer to the same array; to copy, create a new array and copy each element.
M wrong rule / right ruleArrayEqualityComparesValues: wrong: a == b is true when a and b hold the same values. | right: == compares whether a and b are the same array, so a copy and its original are not ==, even with equal elements.
T uneven-application ruleApplies the copy rule unevenly: copies element by element in one place but writes b = a in another and expects b to be independent.
N identity ruleArray copy: a second, independent array holding the same elements as the first.
S declarative ruleTo copy an array, create a new array of the same length and copy the elements one by one: double[] b = new double[N]; for (int i = 0; i < N; i++) b[i] = a[i]; (java.util.Arrays.copyOf does the same).
LT operational sequencing ruleSequencing: new creates the second array first, then the loop copies a[0], a[1], ... in order into b[0], b[1], ...; after the loop, a and b are separate arrays with equal elements.
OP evaluation / result ruleResult: after copying, b[i] == a[i] for every i, but a == b is false; after b[0] = 9, a[0] is unchanged.
OS state-transition ruleState transition: each pass of the copy loop sets one element of the new array and leaves the original unchanged.
R composition rule (with a neighbour)with array_traversal: The copy is a traversal of every index of the original.
R composition rule (with a neighbour)with array_aliasing: b = a makes an alias of the same array; a copy is a different array: changes through one are not seen through the other.
P plan / role rulePlan: copy an array when the original must stay unchanged while the copy is modified (for example shuffling or sorting a copy).
C conservation ruleConservation: changing the copy never changes the original, and the reverse; with an alias every change is shared.
D error rulerule broken: Assignment copies the reference, not the elements. (silent logic error)
X applicability ruleWhen an algorithm must change an array but the original is still needed, work on a copy made with new and a loop (or Arrays.copyOf).

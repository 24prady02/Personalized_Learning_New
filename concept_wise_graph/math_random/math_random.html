Rules of the concept (18)

Book (SW-1e, p. 33 (pdf 43)): “This program uses the Java method Math.random() to generate a random number r in the interval [0, 1)”
Book (SW-1.2, ): “int value = (int) (r * n);”
Rule typeRule
E folk-meaning ruleFolk meaning: 'a random number between 0 and 1' includes both ends, and a 70% chance means the event will happen next time. Java rule: Math.random() returns a double in the half-open interval [0, 1) (0 possible, 1 never), and a probability only describes long-run frequencies over many calls.
M wrong rule / right ruleProbabilityIsPrediction: wrong: A probability (e.g. 70%) predicts what the next single trial will do. | right: A probability describes the long-run frequency over many trials, not one outcome; Math.random() < 0.7 is true on about 70% of many calls, and any single call can go either way.
M wrong rule / right ruleRandomCanReturnOne: wrong: Math.random() can return exactly 1.0. | right: Math.random() returns a value in [0, 1): 0 is possible, 1 is not; hence (int) (Math.random() * N) is at most N-1.
T uneven-application rulePoints to LT (each call produces a fresh value, which is then scaled and cast). Applied unevenly: the student reuses one random value for two separate Math.random() calls on some lines (e.g. assumes the x and y coordinates are equal) or scales without casting on one pass.
N identity ruleMath.random() is a Math library method with no argument that returns a (pseudo-)random double uniformly distributed in [0, 1).
S declarative ruleEach call returns a new double r with 0 <= r < 1; multiplying by N gives a value in [0, N), and casting truncates it to an int between 0 and N-1.
LT operational sequencing ruleIn int n = (int) (r * N) with r = Math.random(): the call produces r, the product r * N is computed in double (N promoted), the parenthesized cast truncates it, then n is assigned.
OP evaluation / result ruleA double in [0, 1) that differs from call to call and run to run (e.g. RandomInt 1000 prints 548, then 141); (int) (Math.random() * 6) + 1 is an int from 1 to 6; Math.random() < 0.5 is true about half the time.
OS state-transition ruleA call changes none of the program's variables, but each call advances the library's hidden generator state, so the next call returns a different value; the drawn value persists only if stored (double r = Math.random();).
R composition rule (with a neighbour)with math_library: Math.random() is the Math method that takes no argument and, unlike the others, is not a function of its input: it returns a random double in [0, 1).
R composition rule (with a neighbour)with explicit_cast: Converting to a random int requires the cast to apply to the whole product: (int) (Math.random() * N); (int) Math.random() * N casts first and is always 0.
R composition rule (with a neighbour)with monte_carlo_simulation: Each trial of a Monte Carlo simulation draws fresh values with Math.random(); estimates become reliable only over many trials.
P plan / role rulePlans: simulate an event of probability p with if (Math.random() < p); pick a random index with (int) (Math.random() * N); generate random points or samples (Sajaniemi role of the drawn value: most-recent holder, overwritten each trial).
C conservation ruleChanging N in (int) (Math.random() * N) changes the range to 0..N-1, and adding a constant shifts it; the output changes from run to run, so a program using Math.random() cannot be checked by comparing exact outputs, only by statistics over many runs.
D error rulerule broken: The scaled range of (int) (Math.random() * N) is 0..N-1. (silent logic error)
D error rulerule broken: A cast applies only to the value immediately after it. (silent logic error)
D error rulerule broken: A double cannot be assigned to an int without a cast. (compile-time)
X applicability ruleUse Math.random() for simulations, games, random sampling and shuffling, where 'every value equally likely' in [0, 1) is the model; it is not suitable when results must be reproducible or follow another distribution without further transformation.

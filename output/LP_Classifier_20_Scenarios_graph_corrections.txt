==========================================================================================
CORRECTIVE ACTIONS FOR ALL PICTURES (fix the drawing once)
==========================================================================================

G1 Edges through circles
  Do not draw an edge as a straight line when it crosses another circle. Either curve it around (a quadratic curve bent away from the circle it would hit), or place nodes so no line crosses a circle: kept nodes in the middle, each neighbour on the side of the kept node it connects to. After layout, test each edge segment against every circle (distance from circle centre to segment < radius + 4 px = crossing) and re-route any that cross.

G2 Hidden arrowheads
  End every line at the edge of the target circle, not its centre: shorten it by the target radius (+2 px), then draw the arrowhead. Now prerequisite arrows into a kept node vanish under the circle, so the direction (A must come before B) is lost.

G3 Misconceptions
  Draw a misconception diamond only when its status in students/<id>.json is not 'refuted'. 'refuted' means the answer disproves it: leave it out, or draw it grey with the word 'refuted' and a legend entry. Fix the Step 4 text the same way ('Misconceptions held' lists only held ones) and remove duplicates.

G4 Levels on nodes
  Each kept node has two levels: Claude's level (Step 6) and the rule level stored in the map. Print both, e.g. 'L4 Claude / L1 rule', or print Claude's level and add a legend line 'number = Claude's level'. 'no level' should read 'no level from Claude (rule L3)'.

G5 Extra node
  The extra node is judge-only and has no edges of its own in the map. Draw it outside the cluster (e.g. top-right corner) with a dashed circle so no edge passes through it. When the extra is also a stored neighbour (S005 boolean_expression, S023 break_statement, S068 markov_chain, S080 comment, S134 variable_swap), keep it at its neighbour position with a dashed outline and the note 'extra + neighbour'.

G6 Kept but not stored
  A concept kept in Step 3 that Claude gave no level is not stored (S023 statement, S068 run). Draw it as a grey circle 'kept, no level, not stored', or add one line under the picture. Otherwise Step 3 and the picture disagree.

G7 Labels
  Put long names on two lines (split at '_') inside or below the circle, and shrink the font for names over 14 characters. Collisions now: S021 'remainder_operatorarithmetic_operators', S001 standard_output, S016 arithmetic_operators/remainder_operator, S057 type_conversion/normalization, S047 FieldWidthIsIntegerDigits.

G8 Neighbour levels
  Neighbours with an inferred level show none. Add it in small grey text under the name, e.g. 'variable (inferred L1)'.

G9 Clutter
  Pictures with 17+ edges (S010 23, S009 21, S057 21, S016 17, S137 17) are hard to read. Optionally draw only edges that touch a kept node and list the neighbour-to-neighbour edges (e.g. primitive_type -> int, int <-> char) in a line under the picture.

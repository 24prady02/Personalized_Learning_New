### Concept: standard_output

  - states_the_rule: print(s) writes s. println(s) writes s and then the line separator. println() only ends the line. A null String prints as "null". By default the stream goes to the terminal window.
  boundary: Covering every part of the code in order is L2.
  boundary: Applying the rule to this code's values is L2. Stating a rule that the language disproves is L0.
L2 Multistructural:

  - output_prediction: The output is the argument's string form. System.out.println(Math.PI) prints 3.141592653589793 (all digits), and println("Sum is " + 1778) prints Sum is 1778 followed by a newline. The methods return void.
  - one_step_execution: One call appends text to the output (println also appends the line separator). It changes no variables and returns nothing.
  boundary: One segment stating the purpose of the whole is L3. A word-for-word transliteration with no interpretation is L0 (Chen score 0).

  - relation_to_neighbour: With `> file`, every print/println/printf writes to the file and nothing appears in the terminal. The program code is unchanged.
  - relation_to_neighbour: A prompt printed with print (not println) shows on the same line where the user then types, before the following StdIn read blocks. Output and input are separate streams.
  - relation_to_neighbour: StdOut text and StdDraw pictures are independent outputs: printing does not draw, and drawing does not print.

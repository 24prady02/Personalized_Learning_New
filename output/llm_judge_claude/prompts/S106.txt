  - diagnose_an_error: rule broken: A ; right after if (...) is an empty statement that forms the whole then branch; the following statement or block is no longer part of the if. Kind: silent logic error. Trigger class: Any if (cond); followed by a stat

  - misconception: wrong rule: Code that compiles is code that works.

L1 Unistructural:

  boundary: Covering every part of the code in order is L2.
  boundary: Applying the rule to this code's values is L2. Stating a rule that the language disproves is L0.

  - output_prediction: Result: for each input the test gives pass (output equals expectation) or fail; the program is accepted only when every chosen input passes.
  - one_step_execution: State transition: one test run leaves the program unchanged and adds one pass or fail to what is known about it.
  boundary: One segment stating the purpose of the whole is L3. A word-for-word transliteration with no interpretation is L0 (Chen score 0).

  - purpose_of_the_whole: Plan: tests give evidence that a program does what it should for the inputs that matter, and catch the cases where it does not.
